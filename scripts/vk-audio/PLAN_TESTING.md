# Проверки VK Audio Downloader

- [x] 1500 записей: один `audio.get(count=2000)` без offset.
- [x] Частичный ответ: следующая страница; пустая/повторяющаяся страница: ошибка.
- [x] ID, audios-ссылка, короткое имя пользователя/сообщества.
- [x] Windows-имена, длинные Unicode-названия, коллизии, повторные audio ID.
- [x] HTTP-сервер: успешный MP3, пропуск существующего, замена нулевого файла.
- [x] 429/503, три повтора, таймаут и оборванный поток.
- [x] HTML/HLS/пустой ответ и 403 не сохраняются в MP3.
- [x] Параллельная загрузка, skipped.log, повторный запуск.
- [x] Понятная ошибка доступа API без утечки токена.
- [x] Полный CLI: два профиля, отдельные папки, повторный запуск и режим `--check` без загрузки.
- [x] Cookies: строка Cookie, JSON с фильтрацией доменов, Netscape с HttpOnly и истёкшей сессией.
- [x] Brave: импорт ограничен VK, ошибки не раскрывают cookies.
- [x] Веб-списки: ограничение первых N, записи без хэшей, повторяющиеся страницы и перенаправление на вход.
- [x] Настоящий HLS с локального HTTP-сервера → MP3 через установленный ffmpeg.
- [x] Реальный веб-режим: доступ подтверждён через Cookie-header, три MP3 скачаны без ошибок.
- [ ] Реальная проверка `--check` с локальным токеном приложения с доступом к аудио API.
- [x] Пробное скачивание трёх записей указанной библиотеки.
- [ ] Полное скачивание указанной библиотеки, сверка счётчиков и числа MP3.
