# poster-microtext

Наносит на изображение сетку микронадписей, читаемых с 10–15 см и невидимых с дистанции.
Работает на любой картинке: цвет букв не фиксированный — каждый пиксель буквы сдвигается
по яркости относительно локального фона (на тёмном участке буквы чуть светлее, на светлом
чуть темнее). Надписи из списка тайлятся «кирпичной кладкой» по всей площади.

Зависимости: только `sharp` из корневого node_modules (текст рендерится системными шрифтами
через SVG). Запуск из корня репо.

## Использование

```bash
# фразы из файла (по одной на строку)
bun scripts/poster-microtext/index.ts -i poster.jpg -o out.jpg --texts phrases.txt

# фразы прямо в аргументах
bun scripts/poster-microtext/index.ts -i poster.jpg -o out.png -t "первая фраза" -t "вторая"
```

## Параметры

Все размеры — **физические** (мм/см); пересчёт в пиксели идёт от `--width-cm`.

| Параметр      | По умолчанию | Что задаёт                                       |
| ------------- | ------------ | ------------------------------------------------ |
| `--width-cm`  | `90`         | ширина отпечатка в см (определяет DPI и масштаб) |
| `--letter-mm` | `1.2`        | высота заглавной буквы в мм                      |
| `--delta`     | `10`         | сдвиг яркости 0–255 (10 ≈ 4%); больше — заметнее |
| `--gap-x-mm`  | `25`         | промежуток между фразами в строке, мм            |
| `--gap-y-mm`  | `18`         | шаг строк, мм                                    |
| `--font`      | `Arial`      | font-family системного шрифта                    |
| `--save-mask` | —            | путь для отладочного PNG с маской текста         |
| `--quality`   | `95`         | качество JPEG (chroma subsampling всегда 4:4:4)  |

Формат вывода — по расширению: `.png`, `.jpg`, `.tif` (LZW). В файл прописывается DPI.

## Физика эффекта

- Острота зрения ~1 угловая минута: буквы высотой ~1.2 мм читаются с 10–15 см
  и физически неразличимы уже с 1–1.5 м.
- Низкий яркостный контраст (±4%) дополнительно прячет сами строки: издалека
  перепад ниже порога контрастной чувствительности, вблизи — различим.
- Комбинация размера и контраста надёжнее любого из приёмов по отдельности.

## Калибровка перед тиражом

Пигментные чернила на матовой бумаге съедают низкоконтрастные перепады сильнее,
чем показывает монитор. Перед финальной печатью сделать тест-полосу: один и тот же
фрагмент с `--delta 6 / 10 / 14 / 18`, напечатать на той же бумаге и посмотреть
с 15 см и с 2–3 метров. Монитору не верить.

- 14000×14000 px обрабатывается ~15 с, память ~1.5 ГБ.
- Проверка раскладки без печати: `--save-mask mask.png` (маска: белое = текст).
