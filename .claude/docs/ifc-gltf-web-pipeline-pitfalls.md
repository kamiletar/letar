# IFC → glTF → браузер: ловушки конвейера

**Коротко:** публичную 3D-модель здания из IFC можно собрать целиком на Node (`web-ifc` +
`@gltf-transform`), без Python в образе, и показать через three.js. Большинство ловушек ниже
выглядят как успех: GLB собирается, модель видна, но материалы склеены, имена узлов не те, а в
файл утекли метаданные автора. Найдено на аудите 2026-09-16, замеры — на реальном IFC ~18 МБ из
Archicad.

## Выбор инструментов

| Задача      | Выбор                                         | Почему                                                                                                  |
| ----------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| IFC → сетки | `web-ifc` (MPL-2.0) в Node                    | 0,8–1,3 с и ~300 МБ RSS против ~11 с у IfcOpenShell; к образу +~7 МБ (`web-ifc-api-node.js` + `.wasm`)  |
| Сжатие GLB  | `@gltf-transform/functions` + `meshoptimizer` | `dedup` → `weld` → `simplify` → `prune` → `meshopt`; 18 МБ IFC → ~390 КБ GLB                            |
| Витрина     | three.js (`GLTFLoader` + `OrbitControls`)     | полный контроль над светом, камерой и заглушкой                                                         |
| AR          | `<model-viewer>`                              | только ради Scene Viewer / Quick Look; для обычного просмотра тяжелее и тянет декодеры с CDN (см. ниже) |

## Конвертация (web-ifc)

- ⚠️ **`GetNameFromTypeCode` отдаёт PascalCase** (`IfcPile`), а константы и привычные сравнения —
  в верхнем регистре (`IFCPILE`). Сравнение без приведения регистра молча не срабатывает ни разу:
  всё уходит в категорию «прочее».
- ⚠️ **`StreamAllMeshes` отдаёт и не-Body представления** (`Curve2D`, `FootPrint`) — без фильтра
  по `RepresentationIdentifier === 'Body'` в 3D попадают плоские контуры поверх геометрии.
- ⚠️ **Стиль на `IfcShellBasedSurfaceModel` не виден у его оболочек** — web-ifc отдаёт геометрию
  по оболочкам, а `IfcStyledItem` висит на родителе. Без явного наследования часть элементов
  получает цвет по умолчанию; признак — счётчик «стиль не найден» больше нуля.
- **Wasm в Next standalone.** `serverExternalPackages: ['web-ifc']` и конкретный файл
  `web-ifc-node.wasm` в `outputFileTracingIncludes`; путь к wasm задавать абсолютным
  (`SetWasmPath(dir, true)`). Проверять наличие файла в `.next/standalone` после сборки — общий
  механизм в [nextjs-standalone-tracing](/.claude/docs/nextjs-standalone-tracing.md) и
  [webpack-emscripten-runtime-wasm-not-emitted](/.claude/docs/webpack-emscripten-runtime-wasm-not-emitted.md).
  На 2026-09-16 это план, не проверенная сборка.

## Что нельзя пускать в публичный файл

⚠️ IFC несёт метаданные, которых не видно в самой модели:

- шапка `FILE_NAME` — **локальный путь к файлу на машине автора** (имена папок, заказчиков),
  автор, организация, время;
- `IfcOwnerHistory` — кто и когда правил; `IfcSite` — широта, долгота, отметка участка;
- `GlobalId` и имена слоёв — внутренние идентификаторы проекта.

Собранный из сеток GLB шапку не несёт, но имена узлов и материалов берутся из данных — их
строить из белого списка (категория + имя стиля), а в тестах искать запретные строки прямо в
байтах GLB. Тестовую фикстуру из реального файла — обезличивать (шапка, координаты, имя проекта).

## glTF-transform

- ⚠️ **`dedup()` склеивает материалы по содержимому, а не по имени.** Два материала с одним
  цветом из разных категорий (кровля и откосы) становятся одним — перекраска «кровли» в
  конфигураторе заденет и откосы. Лечится `dedup({ keepUniqueNames: true })`.
- `simplify` по документации gltf-transform ставится после `weld`: без сваренных вершин
  упрощать почти нечего.

## Браузер

- ⚠️ **`GLTFLoader` меняет имена узлов** (`PropertyBinding.sanitizeNodeName`: пробелы → `_`,
  часть символов выкидывается). Искать узел по точному имени из конвертера нельзя — брать
  категорию по префиксу до разделителя (`roof__…`).
- ⚠️ **`<model-viewer>` не подключает декодер meshopt сам**, а декодеры KTX2 и Draco по
  умолчанию грузит с `gstatic.com`. Сжатый meshopt GLB без явного `MeshoptDecoder` не
  откроется; для внутреннего контура — положить декодеры к себе. В three.js декодер берётся из
  самого пакета (`three/examples/jsm/libs/meshopt_decoder.module.js`).
- three.js подгружать динамическим `import()` при появлении блока в зоне видимости и держать
  заглушку (картинку) на случай отсутствия WebGL.

## Площади помещений

У помещений из IFC бывают дублирующиеся грани. Площадь по сумме треугольников получается
завышенной — считать через объединение полигонов проекции (`polygon-clipping`).

## Тесты

- Юнит-тесты разбора бинарных файлов — в среде node (`// @vitest-environment node` первой
  строкой), если у проекта по умолчанию jsdom: wasm-библиотеки и типизированные массивы под
  jsdom ведут себя иначе, чем в проде.
- WebGL в headless Chromium (Playwright): `--use-angle=swiftshader --enable-unsafe-swiftshader`,
  иначе контекст не создаётся и тест видит только заглушку.
