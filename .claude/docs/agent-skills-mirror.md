# Общий каталог skills для Claude Code и Codex

`.agents/skills/` — единственный редактируемый источник навыков. Здесь находятся обычные skills
и workflows, перенесённые из `.claude/commands/`. Codex читает его напрямую.

Claude Code ищет проектные навыки в `.claude/skills/`, поэтому
`bun scripts/sync-agent-skills.ts` создаёт там точную производную копию. Оба каталога
коммитятся, чтобы свежий клон работал без подготовительного шага. Копию руками не редактируй.

После изменения исходника запусти `bun scripts/sync-agent-skills.ts`, затем
`bun scripts/sync-agent-skills.ts --check`. Проверка запускается в CI через `check-all.mjs`; перед коммитом
изменений навыков запусти её локально. На Windows использована копия вместо Git-симлинков: симлинки требуют особой
настройки при создании и клонировании, а копия проверяется автоматически.

Часть полей frontmatter и подстановок аргументов поддерживается только Claude Code. В общем
тексте нужно описывать workflow так, чтобы другие агенты могли взять параметры из запроса.

Специализированные роли используют тот же принцип: содержимое шести действующих
ролей лежит в одноимённых skills, а `.claude/agents/*.md` задают только
Claude-специфичные модель, инструменты и загрузку skill через `skills:`.
В Codex это обычные навыки, которые можно применить в текущей задаче.
