# Зеркало `.agents/skills/` для сторонних агентов

Каталог `.agents/skills/` — копия `.claude/skills/` для агентов, которые не понимают формат
Claude Code (в частности ChatGPT/Codex — владелец репозитория пользуется им наравне с Claude
Code). `.claude/skills/` остаётся единственным источником истины.

## Как это устроено

- Каталог в `.gitignore` — не коммитится, это генерируемый артефакт, а не отдельная копия
  документации, которую нужно вести вручную.
- Пересобирается скриптом `scripts/sync-agent-skills.ts`:

  ```bash
  bun scripts/sync-agent-skills.ts           # пересобрать зеркало
  bun scripts/sync-agent-skills.ts --check   # только проверить расхождение, exit 1 если есть
  ```

- Скрипт зеркалит `.claude/skills/**` один в один и дополнительно превращает несколько
  общерепных команд из `.claude/commands/` в скиллы `source-command-<slug>` (список — константа
  `MIGRATED_COMMANDS` в самом скрипте). Приложенческие команды (`/aboi`, `/studio` и т.п.) туда
  сознательно не включены — для стороннего агента без контекста Claude Code это шум.
- Всё, чего нет в источнике, при пересборке удаляется из зеркала — руками зеркало не редактируют.

## Когда запускать

**Вручную после правки `.claude/skills/` или мигрированной команды из `MIGRATED_COMMANDS`.**
Автозапуска (git hook / Nx target) нет — скрипт сознательно не встроен в pre-commit, чтобы не
привязывать генерацию untracked-каталога к каждому коммиту в `.claude/`. Агент, редактирующий
скиллы, должен сам вызвать команду после правки, если предполагает, что зеркало кто-то читает
в ближайшее время.

## Почему это отдельное правило

Первая версия зеркала была одноразовым снимком стороннего агента (~31.07.2026, до появления
скрипта) и разошлась с источником: чистка устаревшего совета `nx sync` (коммит `5cb023ea`,
корневой `PLAN.md` §29) прошла по `.claude/skills/`, но не по `.agents/skills/` — те же шесть
вхождений остались в `nx-monorepo/SKILL.md`, `nx-monorepo/reference/{troubleshooting,project-structure,commands}.md`,
`nextjs-expert/reference/troubleshooting.md`. Совет неверен для этого репо: генератор
`@nx/js:typescript-sync` отключён в `nx.json`, `nx sync` references не обновит. Игнорирование
каталога в git расхождение не лечит — сторонний агент, читающий `.agents/`, продолжал бы получать
устаревшие инструкции. Отсюда решение: зеркало — не отдельная сущность для ручного сопровождения,
а производный артефакт с одной командой пересборки.

## Смежная проблема — не решена этим документом

Корневой `AGENTS.md` (untracked, тоже, по всей видимости, сгенерирован Codex) — не копия
`CLAUDE.md`: кто-то механически заменил `.claude/` → `.Codex/` (с большой буквы) по всему тексту,
из-за чего все ссылки на доки в нём битые (`/.Codex/docs/...` вместо `/.claude/docs/...`).
Это отдельный вопрос, решение по нему за владельцем репозитория — данный скрипт `AGENTS.md`
не трогает и не генерирует.
