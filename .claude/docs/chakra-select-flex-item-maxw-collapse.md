# `Field.Select` в flex-строке: обёртка только с `maxW` схлопывается до одной стрелки

⚠️ Выглядит как «селект сломался»: от него остаётся одна стрелка, подписи нет. Ошибок в консоли
нет, typecheck и тесты зелёные.

## Симптом

Фильтр в строке с другими элементами (`HStack`, `Flex`, `Wrap`):

```tsx
<HStack>
  <Input placeholder="Поиск" />
  <Box maxW="280px">
    <Form.Field.Select name="category" options={options} />
  </Box>
</HStack>
```

Ширина обёртки на экране — несколько десятков пикселей, внутри видна только стрелка индикатора.
Найдено 2026-09-23 на странице материалов в админке, затем ещё в 7 местах одного приложения
(`maxW="xs"`, `maxW="32"`, `maxW="36"`, `maxW="56"`).

## Механизм

- У flex-элемента ширина по умолчанию `auto`: она считается от содержимого.
- Триггер Chakra `Select` занимает `width: 100%` родителя. Процент от ширины, которая сама
  зависит от содержимого, браузер не может посчитать, и в расчёте размера содержимого эта ширина
  не участвует.
- Подпись выбранного значения обрезается многоточием, поэтому её минимальная ширина близка к
  нулю. Сжимаемый flex-элемент (`flex-shrink: 1`, `min-width: auto`) уходит до минимальной
  ширины содержимого, то есть до ширины стрелки.

`maxW` задаёт только верхнюю границу. Ширины, от которой можно отталкиваться, он не даёт.

## Фикс

Задать ширину явно, а `maxW` оставить ограничением для узкого экрана:

```tsx
<Box w="240px" maxW="full">
  <Form.Field.Select name="category" options={options} />
</Box>
```

Вариант для колонки, где селект должен занять остаток строки: `flex="1" minW="0"`.

## Как найти все места

```bash
grep -rn -B1 -A3 '<Box maxW=' apps/<app>/src | grep -B2 'Field.Select\|Select\.'
```

Проверять глазами на странице: `boundingBox()` обёртки селекта через Playwright, ширина должна
совпадать с заданной.

обе ошибки выглядели как одна.
