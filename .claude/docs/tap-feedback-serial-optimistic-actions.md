# Отдача на серийное действие: «тап»-эффекты поверх оптимистичной мутации

Когда открывать: пользователь выполняет одно и то же действие много раз подряд (утверждает
строки, отмечает задачи, разбирает очередь), и кнопке нужна заметная отдача — вылетающее число,
серия, финал. Прецедент — журнал в приватном приложении (2026-10-06), детали в его `PLAN.md`.

## Какой эффект выдерживает серию

Полноэкранное конфетти на каждое нажатие мешает уже на третьем: человек жмёт раз в секунду, а
эффект длится две. Рабочая схема — три уровня:

| Событие                    | Эффект                                           | Длительность |
| -------------------------- | ------------------------------------------------ | ------------ |
| каждое нажатие             | кнопка пружинит, из точки нажатия вылетает число | до 0,7 с     |
| нажатия подряд (окно ~3 с) | счётчик серии, искры, число крупнее              | до 0,7 с     |
| очередь разобрана до конца | конфетти, итог строкой                           | до 2 с       |

Число должно что-то значить: сумма, время, очки. «+1» без смысла надоедает так же быстро.

## Чтобы не тормозило

- **Эффекты живут вне React.** Вылетающее число — узел, добавленный в `document.body`, с
  CSS-анимацией; масштаб и снос передаются CSS-переменными. Ни одного `setState` на кадр.
- **Только `transform` и `opacity`.** Вспышка строки — отдельный абсолютный слой с `opacity`, а
  не анимация `background-color`: фон перерисовывает строку целиком.
- **Число, которое «докручивается»,** пишет текст прямо в узел через `ref` и
  `requestAnimationFrame`. У такого `<span>` не должно быть React-ребёнка: React обновит свой
  текстовый узел, который эффект уже заменил, и значение на экране перестанет меняться.
- **`canvas-confetti`** по умолчанию считает частицы в воркере на `OffscreenCanvas`. Грузить его
  динамическим `import()` при первом действии, а не вместе со страницей.
- **Блок с итогом серии появляется вместе с данными,** а не по первому нажатию: иначе строка
  сводки переносится, таблица сдвигается, и следующий клик попадает мимо кнопки.
- **Ширина колонки кнопок фиксирована и достаточна.** Если после действия набор кнопок меняется,
  а колонка растягивалась по содержимому, строка дёргается под курсором.
- `prefers-reduced-motion` — оставить смену статуса и цифры, убрать движение. У `canvas-confetti`
  для этого есть `disableForReducedMotion`.

## ⚠️ Ловушки

**Колбэки второго аргумента `mutate()` срабатывают только для последнего вызова.** При серии
`mutation.mutate(id, { onError })` отказ сервера по третьей записи из пяти до `onError` не дойдёт:
TanStack Query вызывает колбэки уровня вызова лишь у самого свежего `mutate()` этого
наблюдателя. Откат учёта (итог серии, счётчики) вешать на `onError` в `useMutation`, а внешний
обработчик передавать в хук и читать через `ref`.

**Отмена обгоняет само действие.** Кнопка «Вернуть» появляется сразу после оптимистичной правки,
а запрос подтверждения ещё летит. Мутация отмены обязана дождаться своей пары — держать
`Map<id, Promise>` незавершённых подтверждений и делать `await` перед запросом отмены. На сервере
условие «ещё можно отменить» ставить в `where` самого обновления (`updateMany` + проверка
`count`), а не отдельным чтением до него.

**Финал срабатывает дважды или ложно.** Момент «очередь пуста» ловится по переходу счётчика
`> 0 → 0` в кеше, куда его кладёт оптимистичная правка. Нужны два предохранителя: флаг «уже
выстрелил» (запоздавший ответ сервера на миг возвращает единицу, следующий снова ноль) и ключ
набора фильтров (переход на другой фильтр с нулём — не финал).

**Гейт хардкодов темы против библиотек, которым нужен HEX.** `canvas-confetti` принимает цвета
только как `#rrggbb`, а `theme:check` не пускает литералы. Цвет берётся из токена и приводится к
HEX самим браузером:

```ts
const raw = getComputedStyle(document.documentElement).getPropertyValue('--chakra-colors-green-solid')
const ctx = document.createElement('canvas').getContext('2d')
ctx.fillStyle = raw.trim()
const hex = String(ctx.fillStyle) // '#16a34a' при любой исходной записи токена
```

Кешировать по `document.documentElement.className` — он меняется при смене темы.

**Ключевые кадры — в обычном CSS-файле.** Chakra v3 молча выбрасывает `@keyframes`, вложенные в
`css`-проп. Правило вне слоёв Chakra перекрывает его свойство целиком: свой `transition` на
кнопке надо писать со всеми нужными свойствами, включая цвета.

**Проверка в скрытой панели браузера.** Пока вкладка предпросмотра не на экране, анимации и
`requestAnimationFrame` стоят: скриншот показывает первый кадр. Факт срабатывания подтверждать
через `MutationObserver` на добавление узлов и чтением итоговых значений, а не одним скриншотом.
