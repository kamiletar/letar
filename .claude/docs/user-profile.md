# Функции профиля пользователя

## Обзор

Приложение включает комплексную систему профиля пользователя со следующими функциями:

**Статус реализации:** 93.75% завершено (7.5 из 8 фаз)

- ✅ Улучшения UI/UX с боковой навигацией и индикатором заполненности
- ✅ Корзина с полным CRUD
- ✅ Список желаний с интеграцией каталога
- ✅ Адреса доставки с автодополнением DaData
- ✅ История заказов с детальным просмотром и сохранением снэпшотов
- ✅ Мерки пользователя с живыми рекомендациями размеров
- ✅ Настройки (уведомления, GDPR-совместимое удаление аккаунта)

- ⏳ Логирование активности (в ожидании)

## Обзор профиля (`/profile`)

### Функции

- **Индикатор заполненности профиля** - Рассчитывает % на основе 6 полей: имя, email, телефон, пол, дата рождения, аватар
- **Цветовая кодировка прогресс-бара:**
  - Зелёный: 100%
  - Синий: 70%+
  - Жёлтый: 40%+
  - Красный: <40%
- **Отображение информации пользователя** с поддержкой OAuth аватара
- **Боковая навигация** с фиксированным позиционированием (скрыта на мобильных < lg)

### Технические детали

- Серверный компонент для свежих данных
- Enhanced Prisma клиент для row-level безопасности
- Интеграция с OAuth провайдерами для аватара

## Редактирование профиля (`/profile/edit`)

### Функции

- Редактирование базовой информации (имя, email, телефон, пол, дата рождения)
- **Загрузка аватара с интерактивной обрезкой:**
  - Использует react-easy-crop для клиентского редактирования изображений
  - Круговая обрезка (соотношение 1:1) с контролем зума (1x-3x)
  - Максимальный размер файла 2MB, валидация типов изображений
  - Поддержка удаления (сохраняет OAuth аватары)
  - Мгновенное обновление UI с локальным состоянием
- **Форматирование номера телефона** (+7 XXX XXX-XX-XX) с автозаменой 8 на +7
- Интеграция с `@letar/forms` (TanStack Form) и Zod v4

### Технические детали

- Клиентский компонент с useActionState
- Обрезка аватара: библиотека react-easy-crop
- Загрузка файлов на `/api/upload/avatar`
- Валидация формы с Zod v4 схемой
- revalidatePath для инвалидации кэша

## Мерки пользователя (`/profile/measurements`)

### Функции

- Ввод мерок тела (бюст, талия, бёдра, рост в см)
- **Живые рекомендации размеров** с алгоритмом взвешенного расстояния:
  - **Точные совпадения** (все параметры совпадают) - зелёный бейдж
  - **Частичные совпадения** (2+ параметра совпадают) - жёлтый бейдж
  - **Ближайшие совпадения** (топ-3 ближайших) - оранжевый бейдж
  - **Весовые приоритеты:** бёдра (1.5x) > бюст (1.2x) > талия (1.0x)
- Клик для автозаполнения предпочтительного размера из рекомендаций
- Интерактивные карточки размеров с эффектами наведения и клавиатурной навигацией
- Работает с неполными данными (1-2 мерки)

### Технические детали

- Серверный компонент для получения данных
- Клиентский компонент для логики рекомендаций размеров
- Алгоритм взвешенного расстояния для подбора размеров
- Рекомендации размеров с учётом пола
- Интеграция с моделью ProductSize

## Адреса доставки (`/profile/addresses`)

### Функции

- Полный CRUD для адресов доставки
- **Автодополнение DaData** для российских адресов
- Ввод телефона с валидацией и форматированием
- Установка адреса по умолчанию (автоматически сбрасывает другие)
- Интеграция с оформлением заказа (SavedAddressSelector)
- Каждый адрес включает: название, полный адрес, имя получателя, телефон

### Технические детали

- Серверный компонент для списка адресов
- Клиентский компонент для формы адреса с DaData
- Серверные экшены для создания/обновления/удаления/установки по умолчанию
- Уникальное ограничение на isDefault для каждого пользователя
- revalidatePath для инвалидации кэша

## Корзина (`/cart`)

### Функции

- Полные CRUD операции (добавление, изменение количества, удаление товаров)
- Расчёт итоговой суммы в реальном времени с правильным склонением
- Пустое состояние со ссылкой на каталог
- Кнопка "Оформить заказ" ведёт на `/checkout`

### Технические детали

- Серверный компонент для свежих данных при каждом посещении
- Enhanced Prisma клиент с eager loading (productItem.variant.product, productItem.size)
- Серверные экшены для мутаций корзины
- Корзина автоматически создаётся для пользователя при первом добавлении
- CartItem имеет уникальное ограничение на (cartId, productItemId)

## Список желаний (`/profile/wishlist`)

### Функции

- Добавление/удаление вариантов товаров в/из списка желаний
- Кнопка-сердечко в карточках товаров (FaHeart/FaRegHeart)
- Сетка с адаптивными колонками (1-4 в зависимости от размера экрана)
- Редирект на страницу входа для неаутентифицированных пользователей
- Toast уведомления для всех действий
- Сортировка по дате добавления (сначала новые)

### Технические детали

- Серверный компонент для отображения списка желаний
- Клиентский компонент для кнопки-сердечка с серверным экшеном
- WishlistItem имеет уникальное ограничение на (wishlistId, productVariantId)
- Оптимистичные обновления UI с revalidatePath

## История заказов (`/profile/orders`)

### Функции

- Просмотр всех прошлых заказов, отсортированных по дате (сначала новые)
- Детальный просмотр заказа (`/profile/orders/[orderNumber]`)
- **Сохранение снэпшотов данных** (названия товаров, цены, размеры на момент заказа)
- Бейджи статусов заказов с цветовой кодировкой:
  - NEW - серый
  - CONFIRMED - синий
  - PROCESSING - оранжевый
  - SHIPPED - фиолетовый
  - DELIVERED - зелёный
  - CANCELLED - красный
- **Уникальные номера заказов** формата: ORD-YYYYMMDD-XXXXX
- Отображение информации о клиенте, адреса доставки, списка товаров, общей суммы

### Технические детали

- Серверные компоненты для получения данных
- OrderItem хранит снэпшот данных (productName, variantColor, sizeName, price)
- Генерация номера заказа: `ORD-${YYYYMMDD}-${5-значный счётчик}`
- Enhanced Prisma клиент фильтрует заказы по userId
- Тип Decimal для totalAmount (хранится в копейках)

## Настройки (`/profile/settings`)

### Настройки уведомлений (`/profile/settings/notifications`)

**Функции:**

- Email уведомления:
  - Обновления статуса заказа
  - Акции
  - Рассылка
- SMS уведомления:
  - Обновления статуса заказа
- Автосохранение при переключении с toast обратной связью
- Откат при ошибке

**Технические детали:**

- Клиентский компонент с оптимистичными обновлениями
- Серверный экшен с обработкой ошибок
- Модель NotificationPreferences (уникальный userId)
- Автоматическое создание при первом посещении, если не существует

### Удаление аккаунта

**Функции:**

- GDPR-совместимое удаление аккаунта
- Диалог подтверждения с детальным объяснением
- **Каскадное удаление** всех данных пользователя:
  - Cart & CartItem
  - Orders & OrderItem
  - Wishlist & WishlistItem
  - Addresses
  - UserMeasurements
  - NotificationPreferences
  - OAuth Accounts
  - Sessions
- Выход и редирект после удаления

**Технические детали:**

- Серверный экшен с транзакцией
- Каскадное удаление в правильном порядке (сначала дочерние записи)
- Вызов signOut() после удаления
- Редирект на главную страницу

### Функции

- Выбор сохранённого адреса с предвыбором адреса по умолчанию
- Возможность добавить новый адрес inline
- Сводка заказа со всеми товарами корзины
- Расчёт итоговой суммы
- Создание заказа со снэпшотом данных
- Редирект на `/checkout/success` после создания заказа

### Технические детали

- Серверный компонент для начальных данных
- Клиентский компонент для выбора адреса
- Серверный экшен для создания заказа
- Генерация номера заказа
- Снэпшот данных из товаров корзины
- Очистка корзины после создания заказа

## Общие технические паттерны

### Серверные компоненты

- Свежие данные при каждом посещении
- Enhanced Prisma клиент с row-level безопасностью
- Async/await для запросов к базе данных

### Клиентские компоненты

- Интерактивность (формы, кнопки, переключатели)
- Оптимистичные обновления UI
- Toast уведомления через Chakra UI Toaster

### Серверные экшены

- Проверки аутентификации
- Enhanced Prisma клиент
- Обработка ошибок с try/catch
- revalidatePath для инвалидации кэша
- Правильные возвращаемые значения (redirect или report)

### Формы

- `@letar/forms` (TanStack Form) — рекомендуемый подход для новых форм
- Zod v4 валидация (`zod/v4`)
- Серверные экшены вызываются из `onSubmit`
- Обработка ошибок на уровне полей и формы
- Legacy: Conform Future API для существующих форм (постепенная миграция)

### Загрузка файлов

- Аватар: `/api/upload/avatar` (макс. 2MB)
- Клиентская обрезка с react-easy-crop
- Валидация: только изображения
- Хранение: `uploads/avatars/`

### Инвалидация кэша

- revalidatePath после мутаций
- Конкретные пути или wildcard паттерны
- Пример: `revalidatePath('/profile/addresses')`

### Контроль доступа

- Enhanced Prisma клиент обеспечивает row-level безопасность
- Политики ZenStack: `@@allow('read', auth() == this.user)`
- Пользователи могут получить доступ только к своим данным
- Админы имеют полный доступ через проверку роли
