# Делаем Вебстудию

Это не про код конкретного приложения — про бизнес самой студии. Прочитай
`.claude/private/WEBSTUDIO.md` целиком (это submodule `letar-private-docs`, приватный, в
публичный `letar` не коммитится).

## Учёт времени

Стартуй таймер: `time_start({ app: "webstudio", description: "планирование развития студии" })`.
Это не биллируемая клиенту работа — по завершении закрывай через `time_discard`
(`.claude/rules/time-tracking.md`), если только сессия не превращается в конкретную
клиентскую задачу (тогда `time_switch` на нужное приложение).

## Что делать в этой сессии

1. Покажи Ками текущее состояние: раздел «Цели», таблицу «Метрики», последнюю запись в
   «Журнал сессий».
2. Спроси, в каком режиме сессия сегодня — три варианта, можно смешивать:
   - **Фиксировать сделанное** — что-то уже произошло с клиентами/заказами, занести в журнал.
   - **Планировать** — выбрать пункт из «Бэклог идей» или завести новый, довести до конкретных
     шагов.
   - **Фантазировать** — свободный брейншторм без обязательства сразу превращать в план;
     записывай интересные идеи в бэклог, не отбрасывай на лету.
3. Если разговор касается конкретных клиентов/проектов/счетов — используй `studio-mcp`
   (`studio_client_*`, `studio_project_*`, `studio_invoice_*`, `studio_recurring_*`) как
   источник истины, не веди учёт клиентов текстом в этом файле.
4. Веди диалог на русском, простым языком (короткие фразы, без канцелярита) — Ками ценит
   честный прямой разбор, а не поддакивание. Если идея слабая — так и скажи, с обоснованием.
5. В конце сессии — допиши запись в «Журнал сессий» (`### YYYY-MM-DD — заголовок`, что
   сделано/решено, что дальше) и, если менялись «Цели»/«Метрики»/«Бэклог», обнови их прямо в
   файле.

## После сессии

Закоммить `.claude/private/WEBSTUDIO.md` **внутри submodule** `letar-private-docs`
(`cd .claude/private && git add WEBSTUDIO.md && git commit -m "..." && git push`), затем
бампнуть SHA в основном репо (`git add .claude/private && git commit -m "chore: bump
letar-private-docs submodule" -- .claude/private`). Подробности работы с submodule —
`.claude/rules/git.md`.
