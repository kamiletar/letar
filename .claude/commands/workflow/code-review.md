# Code Review - Ревью кода

Проведи ревью кода для указанных файлов или последних изменений.

## Когда использовать

- После завершения фичи перед коммитом
- При ревью PR от другого разработчика
- Для проверки качества существующего кода

## Шаги

1. **Определи scope ревью**
   - Конкретные файлы или `git diff`
   - Прочитай изменённые файлы

2. **Проверь качество кода**
   - DRY (Don't Repeat Yourself)
   - SOLID принципы
   - Читаемость и именование
   - Комментарии на русском языке

3. **Проверь безопасность**
   - SQL injection (используй ZenStack)
   - XSS (экранирование в JSX)
   - CSRF (server actions)
   - Secrets не в коде

4. **Запусти автоматические проверки**

   ```bash
   nx format <app>           # Форматирование
   nx lint <app>             # oxlint → ESLint (автоматически)
   nx typecheck:tsgo <app>   # Проверка типов
   ```

5. **Проверь специфику проекта**
   - Формы через `@letar/forms`
   - Валидация через `zod/v4`
   - Импорты из `@/generated/`

## Чеклист

- [ ] Нет дублирования кода
- [ ] Понятные имена переменных/функций
- [ ] Нет хардкода (магических чисел/строк)
- [ ] Обработка ошибок
- [ ] Типизация без `any`
- [ ] Нет console.log в продакшн коде
- [ ] Комментарии на русском

## Результат

Выведи отчёт:

- Критичные проблемы (блокеры)
- Рекомендации по улучшению
- Позитивные моменты
