# Debug - Отладка и исправление багов

Найди и исправь баг систематическим подходом.

## Когда использовать

- Обнаружен баг в приложении
- Неожиданное поведение
- Ошибки в консоли/логах

## Шаги

1. **Воспроизведи баг**
   - Опиши шаги воспроизведения
   - Определи ожидаемое vs фактическое поведение
   - Проверь в разных браузерах/условиях

2. **Локализуй проблему**
   - Проверь консоль браузера
   - Проверь серверные логи
   - Используй React DevTools
   - Добавь console.log/debugger

3. **Найди root cause**
   - Проследи поток данных
   - Проверь типы входных данных
   - Проверь edge cases

4. **Исправь баг**
   - Минимальное изменение
   - Не ломай другой функционал

5. **Напиши регрессионный тест**

   ```typescript
   it('should handle edge case X', () => {
     // Тест который падал до фикса
   })
   ```

6. **Проверь фикс**
   ```bash
   nx test <app>
   nx e2e <app>-e2e
   ```

## Инструменты отладки

### Browser DevTools

- Console для ошибок
- Network для запросов
- React DevTools для состояния

### Server-side

```typescript
console.log('Debug:', variable)
// Или используй Logger из @letar/label-printer-core
```

### Database

```bash
nx db:studio <app>  # Prisma Studio
```

