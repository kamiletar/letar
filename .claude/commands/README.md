# Конвенция слэш-команд

Каждый файл `.claude/commands/**/*.md` — это слэш-команда Claude Code. Обязательный шаблон
frontmatter (см. `PLAN-INFRA.md` §26):

```markdown
---
description: <одна фраза на русском, что делает команда>
---

# Заголовок

Тело команды...
```

## Правила

- **`description` — обязательно всегда.** Используется для отображения команды в списке
  доступных (`/help`, автодополнение). Без него команда в списке выглядит как голое имя файла.
- **`allowed-tools` — только если тело команды систематически, как часть основного потока,
  вызывает конкретные инструменты** (обычно `Bash` для git/nx/bun/ssh-цепочек). Не добавляй его
  ради одной иллюстративной команды в примере — тогда разрешение всё равно будет запрошено при
  первом реальном вызове, что нормально. Добавляй, если без разрешения команда встанет на
  промпте на первом же шаге своего штатного алгоритма (пример: `end-session.md` — `git commit`
  обязательный финальный шаг, `infra/db-migrate.md` — весь смысл команды в цепочке
  `nx zenstack:generate`/`db:push`/`db:migrate`).
- **`arguments`** — опционально, для команд с параметрами (`workflow/refactor.md` — пример).

## Почему это важно

Без `allowed-tools` во frontmatter команда, которой нужен Bash, упирается в промпт на разрешение
каждый раз заново — уже наступали на этом при проектировании `/repo` (PLAN-INFRA.md §25, Шаг 5).
Единообразный frontmatter с самого начала — дешевле точечных патчей постфактум.
