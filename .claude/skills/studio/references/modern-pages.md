# Современная зона Studio

Читай перед изменением публичных страниц, перехода из CRT, превью проектов или
разбором hydration на локализованных URL. Основание: локальная реализация и проверки
21.11.2026, коммиты Studio `335ccf3` и `8f9a15c`. Текущее состояние сверяй с Git и задачами.

## Обязательные границы

- Главная остаётся CRT в `(public)`. Публичные современные разделы размещаются в
  `src/app/(modern)/[locale]` с общим ModernLayout. Перед переносом проверь старую
  группу: две страницы с одинаковым URL в разных route groups конфликтуют.
- Сохраняй ключи `src/i18n/routing.ts`, metadata/alternates и локализованный Link.
  Например, `/work` — ключ; `/raboty`, `/en/work`, `/ja/work` — адреса посетителя.
  Перенос между группами сам по себе не требует менять URL.
- Из CRT используй существующий ModernJumpLink, в современной зоне — обычный
  локализованный Link. Общий EraLoader уже различает программу раздела; отдельная
  заставка страницы не нужна. Back, reduced-motion и модифицированный клик — часть
  существующего контракта, а не повод повторно запускать церемонию входа.
- Не совмещай ModernProviders с фосфорной темой или BackofficeShell в одном разделе:
  токены пишутся на `:root`. Партнёрская посадочная уже перенесена в `(modern)`;
  её прежние шапка и подвал удалены в пользу общей оболочки.
- При переделке заявки сохраняй LeadForm: тему `?topic=`, серверное действие,
  реферальный код, явное согласие и ссылку на политику. Дизайн не требует новой формы.
  У партнёрства сохраняй проверку приглашения/сессии, вход `/partner/join` и кабинет
  `/agent`. Условия программы сверяй с partner-workflow.md, не выводи их из макета.

## Проверенный вариант по умолчанию

Используй существующие modern semantic tokens и токены полей портфолио. Композиции
с конкретным контентом Studio остаются локальными; повторяемые средства интерфейса
оценивай отдельно на shared-first. Памятки по страницам находятся в приложении:
`apps/studio/docs/modern-pages.md`, `docs/portfolio.md`, `docs/home-main-menu.md`.
Подробности поведения храни там; этот справочник задаёт порядок решений.

Для портфолио использованы реальные снимки публичных страниц в `public/work/*.webp`.
Не снимай закрытые кабинеты с клиентскими данными ради превью. Управляемая прокрутка
снимка остаётся явно обозначенным превью; её нельзя описывать как работающий продукт.
Сохраняй связь бренда с исходным кейсом через itemIndex. Снимок не доказывает результат
клиента и не закрывает права на публикацию, инвентаризацию или redirects из ST-066.

## Типичные ошибки и подводные камни

- **Разные первые кадры при rewrite.** Серверный pathname может отличаться от URL
  браузера. В EraLoader первый кадр одинаков, чтение клиентского пути отложено до
  монтирования через requestAnimationFrame с отменой при cleanup. Проверяй SSR/hydration
  прямым заходом, а не только переходом внутри приложения. Синхронный setState в effect
  здесь отклонялся oxlint; скрытие предупреждения не исправляет несовпадение разметки.
- **Неверный раздел переводов.** В messages есть и `hero.tiles.about`, и корневой
  `about`. Строковая замена первого вхождения попала в пункт меню, и h1 показал ключ
  `about.modernTitle`. Меняй точный namespace и проверяй видимый заголовок на ru/en/ja.
- **Скриншот без lazy-превью.** Full-page capture сам по себе не гарантирует загрузку
  изображений ниже экрана. Для визуальной проверки прокрути кейсы в область видимости
  и дождись загрузки/декодирования снимков перед capture.
- **Локальная схема вместо ошибки дизайна.** На базе этой сессии отсутствовал
  `StudioSettings.defaultPartnerPoolBps`. Страница скрывает процент/калькулятор только
  при этой конкретной ошибке. Не подставляй выдуманные условия и не меняй рабочую БД
  ради скриншота. Сверка — ST-102; при продолжении проверь её актуальный статус.
- **Локально готово ≠ опубликовано.** Коммиты выше не включали push, root SHA/lock,
  полную сборку, staging gate, банковские действия или production. Не выдавай их за
  проверку калькулятора с настройкой из БД либо за разрешение на деплой.

## Проверка изменений

Проверенные команды из корня с установленными зависимостями:

```powershell
$env:NX_DAEMON='false'
nx run-many -t format --projects=studio --output-style=static
nx lint studio --output-style=static
nx typecheck:tsgo studio --output-style=static
nx test studio --output-style=static --run era-loader.test.tsx partner-program.test.ts lead.action.test.ts
```

В сессии выполнено 26 тестов; это исторический результат, не ожидаемое число навсегда.
Для браузера сработал установленный Playwright с
`chromium.launch({ channel: 'msedge', headless: true })`; managed Chromium отсутствовал.
Используй доступный браузер, не устанавливай зависимости заново только ради этого примера.
Игнорируемые раннеры `.claude/artifacts/` не гарантированы в другом checkout.

Проверяй прямой заход на ru/en/ja, отсутствие pageerrors/переполнения от 320px,
обе темы, клавиатуру, reduced-motion, обычный CRT-переход и Back. Для портфолио —
выбор на desktop, вертикальную ленту mobile, открытие кейса и остановку прокрутки
превью; без JS доступны все кейсы и native details. После смены общей шапки проверь
видимые заголовки: прежняя партнёрская Heading recipe давала слишком тесный интерлиньяж.
Форму проверяй без отправки реальных заявок, если их создание не входит в задачу.
