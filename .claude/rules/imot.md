# IMOT — Платформа психотерапии

## Описание

IMOT — платформа для онлайн-консультаций с психотерапевтами. Клиенты записываются на сессии, специалисты ведут приём.

## Основные сущности

| Модель       | Описание                                         |
| ------------ | ------------------------------------------------ |
| `User`       | Пользователь (роли: CLIENT, SPECIALIST, ADMIN)   |
| `Specialist` | Профиль специалиста (образование, специализации) |
| `Session`    | Сессия консультации                              |
| `Booking`    | Запись на сессию                                 |
| `Review`     | Отзыв клиента                                    |

## Роли и доступ

```typescript
enum Role {
  CLIENT      // Клиент — запись, отзывы
  SPECIALIST  // Специалист — ведение сессий, расписание
  ADMIN       // Администратор — полный доступ
}
```

## Структура приложения

```
apps/imot/

│   ├── admin/            # Админ-панель
│   └── api/
├── schema.zmodel

```

## Особенности

- **Видеозвонки** — интеграция с Whereby/Daily.co (планируется)
- **Расписание** — слоты по 50 минут
- **Приватность** — строгие access policies для данных клиентов
