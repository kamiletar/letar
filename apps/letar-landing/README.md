# letar-landing

Визуальная карта проектов экосистемы Letar. Объединяет Studio Letar, личный сайт Kami,
веб-приложения, десктопные и мобильные продукты, инфраструктуру и библиотеки.

Главная строится вокруг живых превью ключевых сайтов. Оптимизированные статические WebP находятся в
`src/assets/projects/` и подключаются через `next/image`; исходные PNG в репозитории не хранятся.
Системные подписи используют локальный Departure Mono (OFL 1.1, текст лицензии рядом со шрифтом).
