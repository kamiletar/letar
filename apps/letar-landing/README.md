# letar-landing

Каталог проектов экосистемы Letar. Объединяет ссылки на веб-приложения, десктопные и мобильные
продукты, инфраструктуру и библиотеки, а также на Studio Letar и личный сайт Kami.

## Документация

| [PLAN.md](./PLAN.md)           | Текущие задачи и приоритеты |
| [CHANGELOG.md](./CHANGELOG.md) | История изменений           |

## Стек

- **Фреймворк:** Next.js 16 (App Router)
- **UI:** Chakra UI v3

## Команды

```bash
nx dev letar-landing
nx build letar-landing
nx lint letar-landing
```
