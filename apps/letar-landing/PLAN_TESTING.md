# План тестирования

## Статистика

| Тип  | Количество | Статус      |
| ---- | ---------- | ----------- |
| Unit | 0          | Планируется |
| E2E  | 11         | Реализовано |

E2E-сценарии запускаются в Chromium, Firefox и WebKit. Проверяются главная страница, актуальность
карточек и ссылок, SEO-файлы, 404, консоль браузера и внутренняя навигация.

## Запуск тестов

```bash
nx test letar-landing
nx e2e letar-landing-e2e
```
