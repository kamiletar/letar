# План тестирования

## Статистика

| Тип  | Количество | Статус      |
| ---- | ---------- | ----------- |
| Unit | 0          | Планируется |
| E2E  | 13         | Реализовано |

E2E-сценарии запускаются в Chromium, Firefox и WebKit. Проверяются новая hero-секция и CTA, реальные
превью избранных проектов, клавиатурное раскрытие категорий, актуальность карточек и ссылок,
SEO-файлы, 404, консоль браузера и внутренняя навигация.

Актуальность каталога отдельно закреплена ссылками на Studio Letar, Kami, «Свои Чужие» и
DomWellbes, а также отсутствием закрытых Premium Rosstil и Integrelle.

Параллелизм ограничен четырьмя workers, чтобы первый webpack compile и генерация вариантов
`next/image` не конкурировали за 30-секундный timeout навигации.

## Запуск тестов

```bash
nx test letar-landing
nx e2e letar-landing-e2e
```
