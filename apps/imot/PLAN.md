# План развития IMOT

> Последнее обновление: 2026-01-17

## 📊 Текущее состояние приложения

### ✅ Что уже реализовано

#### 👥 Функционал для специалистов

- **Управление клиентами**
  - Список клиентов с карточками
  - Создание/редактирование профиля клиента
  - 5 типов профилей: телесный, энергетический, нейропсихологический, стилевой, нумерологический
  - Детальный просмотр клиента со всеми профилями

- **Управление сессиями**
  - Список сессий с фильтрацией по статусам
  - Создание/редактирование сессий
  - Статусы: SCHEDULED, COMPLETED, CANCELLED, NO_SHOW
  - Календарь сессий

- **Планы трансформации**
  - Создание планов для клиентов
  - Назначение практик в планы
  - Отслеживание прогресса

#### 🧘 Функционал для клиентов

- **Практики**
  - Список назначенных практик
  - Отметка практики как выполненной
  - Добавление заметок к практикам
  - Фильтрация по статусу выполнения

- **История прогресса**
  - График прогресса за последние 90 дней
  - Статистика выполнения практик

- **Сессии**
  - Просмотр расписания сессий
  - История прошедших сессий

#### 🔐 Аутентификация

- Регистрация с email/паролем
- Вход с email/паролем
- OAuth провайдеры (Yandex, Telegram)
- Роли: ADMIN, SPECIALIST, CLIENT
- Защита роутов по ролям

#### 🛡️ Безопасность (v0.34.0)

- ✅ ZenStack access control во всех Server Actions
- ✅ Корректные политики доступа для User, Practice, Account, Session, Verification
- ✅ SPECIALIST видит только своих клиентов
- ✅ Клиент не может удалять практики

#### 🎨 UI/UX

- Chakra UI v3 компоненты
- Адаптивный дизайн
- Брендовая цветовая схема
- Loading состояния
- Error boundaries
- Темная тема (next-themes)

## 🗓️ Рекомендуемая последовательность

### Фаза 1: Модернизация форм и UX (React 19 + TanStack Query)

**Цель:** Улучшить пользовательский опыт через применение современных паттернов.

**Документация:** См. `.claude/docs/data-fetching.md` для подробных примеров.

#### 1.1 Внедрение useOptimistic для интерактивных элементов

**Приоритет:** 🔥 Критический (максимальный UX эффект)

- [ ] **Практики клиента** (practice-card.tsx)
  - Toggle выполнения практики (isCompleted)
  - Мгновенное сохранение заметок
  - Instant visual feedback

**Ожидаемый результат:**

- Мгновенная обратная связь при отметке практики
- Улучшение engagement с практиками на 30-40%

#### 1.2 Миграция форм на useActionState

**Приоритет:** ⚡ Высокий (упрощение кода)

- [ ] **Формы аутентификации** (signin-form.tsx, register-form.tsx)
  - Убрать useState для loading/error states
  - Унифицировать обработку ошибок
  - Создать Server Actions для signin/register

- [ ] **Формы профилей клиента** (body-profile-form, energy-profile-form и т.д.)
  - Проверить использование useActionState
  - Стандартизировать паттерн

**Ожидаемый результат:**

- Сокращение кода форм на 30-40%
- Единый паттерн для всех форм

#### 1.3 Внедрение TanStack Query для списков

**Приоритет:** ✅ Средний (продвинутый UX)

- [ ] **Список практик клиента** (practices/page.tsx)
  - useFindMany для кэширования
  - Синергия с useOptimistic
  - Автоматическое обновление после toggle

- [ ] **Списки специалиста** (clients, sessions, plans)
  - Кэширование при навигации
  - Real-time обновления
  - Фильтрация без перезагрузки

**Ожидаемый результат:**

- Улучшение Time to Interactive на 40-50%
- Мгновенная навигация между списками

#### 1.4 Infinite Scroll (опционально)

**Приоритет:** ⏳ Низкий

- [ ] **История прогресса** (progress/page.tsx)
  - useInfiniteFindMany для постепенной загрузки истории
  - Загрузка по месяцам

**Ожидаемый результат:**

- Масштабируемость при большом объеме данных

#### Технические требования

**Зависимости:**

- ✅ React 19 - установлен
- ✅ @tanstack/react-query - установлен
- ✅ ZenStack - настроен
- ⚠️ QueryProvider - НУЖНО добавить в layout.tsx

**Критичные файлы:**
