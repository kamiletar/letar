# План тестирования — НейроАбоИ

## Слой 1 — Юнит-тесты (Vitest)

- [ ] Утилиты расчёта цены: `calcOrderTotal(items, promo, certificate)` — все ветки скидок
- [ ] Утилиты формирования цены за погонный метр: `calcLineTotal(lengthMeters, pricePerMeter)`
- [ ] Парсинг и валидация промокода: формат, срок действия, лимит использований
- [ ] Парсинг и валидация подарочного сертификата: код, остаток, срок
- [ ] Реферальная ссылка: генерация, парсинг входящего ref-параметра, привязка к заказу
- [ ] Schema-валидация Zod для форм (адрес доставки, чекаут, регистрация)

## Слой 2 — Интеграционные (компонентные) тесты

- [ ] Карточка товара рендерит цену, выбор длины, добавление в корзину
- [ ] Корзина: добавить → изменить количество → удалить → пересчёт суммы
- [ ] Чекаут: валидация полей, применение промокода/сертификата, переход к оплате-заглушке
- [ ] Регистрация / логин: успешный путь + ошибки
- [ ] Гостевой чекаут: завершение заказа без аккаунта

## Слой 3 — E2E (Playwright)

### Critical user flow (smoke)

- [x] Открыть главную → перейти в каталог → открыть карточку → добавить в корзину → оформить заказ как гость
- [x] Пустая корзина → редирект на /cart при переходе на /checkout (v0.15.0)
- [x] Валидация полей checkout: HTML5 блокирует пустую форму, остаётся на /checkout (v0.15.0)
- [x] Заполнение формы вручную (без DaData) + MANAGER_CALL → success страница ORD-... (v0.15.0)
- [x] Невалидный email: ошибка появляется, при исправлении исчезает (v0.15.0)
- [x] DaData автоподсказки: мок через page.route + выбор адреса заполняет поле (v0.15.0)
- [ ] Регистрация → логин → переход в ЛК → история заказов
- [ ] Логин → добавление товара в избранное → проверка появления в избранном
- [x] Валидация полей checkout: обязательные поля, некорректный email (v0.14.1)
- [ ] Оформление заказа с применением промокода (скидка пересчитывается корректно)
- [ ] Оформление заказа с погашением подарочного сертификата
- [ ] Переход по реферальной ссылке → регистрация → пометка заказа реферальной связью

### Адаптивность

- [ ] Мобильный (375×667): главная, каталог, карточка, корзина, чекаут — без горизонтального скролла, кнопки ≥ 44px
- [ ] Планшет (768×1024): сетка каталога 2 колонки
- [ ] Десктоп (1280+): сетка каталога 3-4 колонки

### Тёмная тема

- [ ] Переключатель работает, контрастность всех текстов ≥ WCAG AA
- [ ] Цвета бренда не теряются на тёмном фоне (терракот → читаемый, фиолет → читаемый)

## Слой 4 — Админка

- [ ] Логин админа защищён `requireAdmin()`
- [ ] Загрузка изображения дизайна → предпросмотр → сохранение в карточке товара
- [ ] Создание промокода → применение на витрине
- [ ] Создание подарочного сертификата → погашение
- [ ] Изменение статуса заказа: новый → оплачен → отправлен → доставлен (триггерит email)

## Слой 5 — SEO и доступность

- [ ] Мета-теги: title, description, OG, canonical на каждой странице
- [ ] sitemap.xml + robots.txt
- [ ] JSON-LD: Organization (главная), Product (карточка)
- [ ] Lighthouse: Performance ≥ 90, Accessibility ≥ 95, SEO 100

## Слой 6 — Безопасность

- [ ] Все формы валидируются Zod с `.strip()` (не пускают лишние поля)
- [ ] Нет небезопасной вставки HTML с пользовательским вводом (используем экранирование React)
- [ ] Защита от CSRF на server actions
- [ ] Rate limiting на auth endpoints
- [ ] Загрузка изображений: проверка MIME, лимит размера, безопасное имя файла
