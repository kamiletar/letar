## Быстрый старт

```bash
nx dev aboi              # http://localhost:3018
nx format aboi           # dprint
nx lint aboi             # oxlint → ESLint
nx typecheck:tsgo aboi   # быстрая проверка типов
nx test aboi             # юнит-тесты
nx e2e aboi-e2e          # E2E (Playwright)
nx build aboi            # production build
```

## Концепция

Декоративные обои с **зашитыми мотивирующими аффирмациями**: дизайнерский паттерн снаружи,
осмысленный язык внутри. Бренд опирается на идею «среда формирует состояние» — слова
(здоровье, сила, энергия, гармония) вплетаются в графику так, что глаз их не «читает»,
а мозг считывает.

> **Важно:** продукт декоративный, не медицинский. Никаких формулировок «лечит»,
> «реабилитация», «одобрено врачами». См. блок дисклеймера в футере.

## Текущий статус

**MVP scope** (по согласованию с Виталием, 2026-05-05):

- ✅ Каталог + карточка товара
- ✅ Корзина + чекаут
- ⏸ Личный кабинет (с историей заказов, избранным, адресами)
- ⏸ Подарочные сертификаты + реферальная программа
- ⏸ Промокоды
- ⏸ i18n (RU на старте, заложить EN/CN на будущее)

**Вторая волна:**

- Платёжный шлюз Тинькофф Эквайринг + СБП
- Доставка СДЭК (API расчёта)
- Кастомный дизайн от клиента (загрузка изображения / своя надпись)
- Блог

**На сейчас:** голый каркас Next.js — главная страница-заглушка, тема (терракот + фиолетово-синий),
Umami аналитика. БД, авторизация, схема — отдельной итерацией.
