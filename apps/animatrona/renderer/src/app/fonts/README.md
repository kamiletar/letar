# Локальные шрифты

Inter лежит здесь файлом и подключается через `next/font/local` в [`../layout.tsx`](../layout.tsx).

## Почему не `next/font/google`

`next/font/google` скачивает шрифт при **каждой** сборке — хрупкость загрузчика, разбор случая с
падением на domwellbes 2026-09-22 — `apps/domwellbes/src/app/fonts/README.md`. Для Electron-сборки
(эта — renderer, `next build` со статическим экспортом) сеть на этапе сборки — тот же риск, только
диагностировать сложнее: сборка идёт локально на машине разработчика, не на выделенном сервере.

## Что внутри

| Файл                         | Гарнитура | Оси                                       | Размер |
| ---------------------------- | --------- | ----------------------------------------- | ------ |
| `Inter-cyrillic-latin.woff2` | Inter     | `wght` 400–700, `opsz` 14–32 (не тронута) | 89 КБ  |

Раньше `next/font/google` грузился без ограничения `weight` вовсе (полный вариативный диапазон,
100–900). Здесь ось `wght` сужена до диапазона, реально используемого в UI —
`fontWeight="normal"/"medium"/"semibold"/"bold"` (400/500/600/700).

Лицензия — SIL Open Font License 1.1, текст рядом: `OFL-Inter.txt`.

## Покрытие символов

Подмножество — диапазоны Google Fonts `latin` + `cyrillic` (ровно те же, что стояли в
`subsets: ['latin', 'cyrillic']`), плюс `←→↔≈≠≤≥✓✗∞▲▼▶★` — приложение активно показывает клавиши
навигации (`←/→` — сдвиг синхронизации дорожек), диапазоны качества (`≥ 2.0`), статусы (`✓`/`✗`),
рейтинги (`∞`, `★` — дорожка по умолчанию) и кнопку воспроизведения (`▶`) прямо в тексте UI, не
иконками.

⚠️ `⋮` (U+22EE, vertical ellipsis, `CommandPalette`/`QuickSearch` описания) в подмножество не
попал — у самого Inter (и в полной вариативной версии, не только в субсете) этого глифа нет
вовсе, браузер всегда рисовал его через fallback-шрифт, до перехода на `next/font/local` включая.
Не регрессия этого перехода.

Emoji (флаги стран в `dub-groups.ts`, 💡✅❌🔥😂 и т.п. в чате) не включены — рисуются системным
emoji-шрифтом через fallback независимо от основного шрифта. CJK-символы в
`app/_actions/search.action.ts` (тестовый пример поискового запроса) — вне охвата: Inter
кириллицу/латиницу не расширяет до иероглифов, полноценный CJK-шрифт сюда не подключался и раньше.

Покрытие проверено разбором `cmap`
([font-cmap-coverage-verification](/.claude/docs/font-cmap-coverage-verification.md)). Русский
алфавит (А–я, Ёё) покрыт полностью.

## Как пересобрать

```bash
python scripts/fonts/subset-google-font.py \
  --slug inter --family-camel Inter \
  --weights 400 700 \
  --unicodes "0000-00FF,0131,0152-0153,02BB-02BC,02C6,02DA,02DC,0304,0308,0329,2000-206F,20AC,2122,2191,2193,2212,2215,FEFF,FFFD" "0301,0400-045F,0490-0491,04B0-04B1,2116" "2190,2192,2194,2248,2260,2264,2265,2713,2717,221E,22EE,25B2,25BC,25B6,2605" \
  --out apps/animatrona/renderer/src/app/fonts/Inter-cyrillic-latin.woff2
```

Общий скрипт — `scripts/fonts/subset-google-font.py`. Требует `pip install fonttools brotli`.
