# FAQ - Часто задаваемые вопросы

## Общие вопросы

### Что такое Label Printer Desktop?

Label Printer Desktop — это desktop приложение для печати этикеток "Честный знак" на термопринтерах TSC. Приложение позволяет сканировать коды маркировки USB сканером или вводить их вручную, а затем печатать этикетки с DataMatrix кодом и штрих-кодом GTIN.

### Какие принтеры поддерживаются?

Приложение разработано для термопринтеров TSC серии TE/TTP/TC, но должно работать с любым принтером, поддерживающим стандартную печать через Windows Print Subsystem.

**Рекомендуемые модели:**

- TSC TE210/TE310
- TSC TTP-244 Pro
- TSC TC200/TC300

### Какие операционные системы поддерживаются?

- Windows 10/11 (основная платформа)
- Linux (экспериментально)
- macOS (экспериментально)

## Установка и запуск

### Как установить приложение?

1. Скачайте установщик с GitHub Releases
2. Запустите `.exe` файл
3. Следуйте инструкциям установщика
4. Приложение будет установлено в `%LOCALAPPDATA%\label-printer-desktop`

### Приложение не запускается, что делать?

**Проверьте:**

1. Антивирус не блокирует приложение
2. Установлен .NET Framework 4.7.2+
3. Есть права на запись в папку `%APPDATA%\label-printer-desktop`

**Логи находятся в:** `%APPDATA%\label-printer-desktop\logs`

### Как обновить приложение?

Приложение автоматически проверяет обновления при запуске. Также можно проверить вручную:

1. Откройте **Настройки** → **О приложении**
2. Нажмите **Проверить обновления**

## Сканер и ввод кодов

### Какие USB сканеры поддерживаются?

Любой USB сканер штрих-кодов, работающий в режиме **HID Keyboard** (эмуляция клавиатуры). Большинство бюджетных сканеров работают именно так.

**Рекомендуемые настройки сканера:**

- Режим: HID Keyboard
- Suffix: Enter (CR)
- Включена поддержка GS1 DataMatrix

### Сканер не распознаётся, что делать?

1. Убедитесь, что сканер в режиме HID Keyboard
2. Проверьте, что сканер отправляет символ Enter (CR) после кода
3. Некоторые сканеры требуют активации поддержки GS1-128/DataMatrix — см. инструкцию сканера
4. Попробуйте другой USB порт

### Как включить симуляцию сканера для тестирования?

На главной странице нажмите кнопку **Симуляция сканера** справа от поля ввода. Это позволяет тестировать приложение без физического сканера.

### Какой формат кодов маркировки?

Приложение поддерживает коды "Честный знак" в формате GS1:

```
01<GTIN-14>21<Serial>91<Crypto>
```

**Пример:** `010461234567890121ABC123456789091XXXX`

- `01` — Application Identifier для GTIN
- `04612345678901` — GTIN-14 (14 цифр)
- `21` — Application Identifier для серийного номера
- `ABC123456789` — серийный номер (до 20 символов)
- `91` — Application Identifier для криптохвоста
- `XXXX` — криптографический код

## Печать

### Этикетка печатается неправильно (сдвинута, обрезана)

**Проверьте настройки принтера:**

1. **Настройки** → **Принтер**
2. Убедитесь, что размеры этикетки соответствуют реальным (например, 40x30 мм)
3. Настройте позицию DataMatrix и GTIN
4. Выполните **Тестовую печать** для проверки

### Как настроить скорость и плотность печати?

1. Откройте **Настройки** → **Принтер**
2. Измените **Скорость печати** (1-6 дюймов/сек)
3. Измените **Плотность** (1-15, выше = темнее)
4. Нажмите **Сохранить**

**Рекомендуемые значения:**

- Скорость: 4 дюйм/сек
- Плотность: 8-10

### Принтер печатает пустые этикетки

1. Проверьте настройки GAP (зазор между этикетками)
2. Выполните калибровку датчика на принтере
3. Убедитесь, что тип носителя (gap/black mark) настроен правильно

### Как напечатать несколько этикеток сразу?

Используйте **Пакетную печать**:

1. Перейдите на страницу **Batch**
2. Загрузите CSV или TXT файл с кодами (один код на строку)
3. Выберите нужные коды галочками
4. Нажмите **Печатать выбранное**

## База данных

### Где хранятся данные?

База данных SQLite находится в:

- **Windows:** `%APPDATA%\label-printer-desktop\database.db`
- **Linux:** `~/.config/label-printer-desktop/database.db`

### Как экспортировать историю печати?

1. Перейдите на страницу **История**
2. Выберите диапазон дат
3. Нажмите **Экспорт в Excel**

### Как экспортировать статистику?

1. Перейдите на страницу **Статистика**
2. Выберите период
3. Нажмите **Экспорт в PDF**

### Как импортировать базу товаров?

1. Перейдите на страницу **Товары**
2. Нажмите **Импорт**
3. Загрузите CSV или Excel файл с колонками:
   - `gtin` — GTIN-13 или GTIN-14
   - `name` — название товара
   - `articleCode` — артикул (опционально)
   - `composition` — состав (опционально)
   - `color` — цвет (опционально)

## Ошибки и решения

### Ошибка "Invalid GTIN checksum"

Контрольная сумма GTIN не совпадает. Проверьте:

1. Правильность отсканированного кода
2. Сканер корректно читает весь код
3. Код не повреждён/не искажён

### Ошибка "Printer not found"

1. Проверьте, что принтер включён и подключён
2. Убедитесь, что принтер виден в Windows → Устройства и принтеры
3. Выберите правильный принтер в **Настройки** → **Принтер**

### Ошибка "Database is locked"

База данных заблокирована другим процессом:

1. Закройте все экземпляры приложения
2. Перезапустите приложение
3. Если не помогло — перезагрузите компьютер

### Ошибка "Print job failed"

1. Проверьте подключение принтера
2. Проверьте наличие бумаги и риббона
3. Посмотрите логи: `%APPDATA%\label-printer-desktop\logs`

## Разработка

### Как запустить приложение в режиме разработки?

```bash
# 1. Генерация схем БД
nx zenstack:generate label-printer-desktop

# 2. Создание базы данных
nx db:push label-printer-desktop

# 3. Запуск dev сервера
nx dev label-printer-desktop
```

### Как собрать установщик?

```bash
# Windows
nx build:win label-printer-desktop

# Результат: dist/label-printer-desktop/*.exe
```

### Где находятся логи в dev режиме?

- **Main process:** консоль терминала
- **Renderer:** DevTools (Ctrl+Shift+I)
