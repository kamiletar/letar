## Запуск тестов

```bash
# Unit тесты
nx test label-printer-desktop

# E2E тесты (когда будут добавлены)
nx e2e label-printer-desktop-e2e
```

## План по фазам

### Фаза 1: Unit тесты сервисов

- [ ] GS1Parser — парсинг кодов маркировки
- [ ] TSPLService — генерация TSPL команд
- [ ] ImageGeneratorService — создание изображений

### Фаза 2: Integration тесты

- [ ] IPC handlers — взаимодействие main/renderer
- [ ] Database — ZenStack операции
- [ ] Settings — сохранение/загрузка конфигурации

### Фаза 3: E2E тесты

- [ ] Полный цикл печати
- [ ] Настройки принтера
- [ ] История печати

## Особенности тестирования Electron

- Main process тестируется отдельно от renderer
- IPC calls требуют mock для contextBridge
- SQLite база для тестов изолирована
