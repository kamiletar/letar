## 🏪 Маркетплейс (Multi-Vendor)

> **Цель:** Превратить магазин в маркетплейс, где другие модельеры одежды продают через платформу Елены Аксяновой.
> Елена принимает оплату, организует доставку, после подтверждения доставки (если нет возврата в течение 7 дней)
> перечисляет продавцу его долю за вычетом комиссии.

### Юридическая модель

**Агентский договор (ГК РФ, гл. 52):**

- Площадка = агент, продавец = принципал. Площадка действует от своего имени, но за счёт принципала
- УСН 6% **только с комиссии** (агентского вознаграждения), НЕ с полного оборота
- Ответственность за качество — несёт продавец
- Возврат предоплаты — площадка обязана вернуть, если товар не передан

**Закон о защите прав потребителей (ст. 26.1):**

- Отказ до получения — в любое время
- Отказ после получения — 7 дней
- Если не предоставлена инфо о возврате — 3 месяца
- Возврат денег — 10 дней с момента требования
- При дистанционной продаже список "невозвратных товаров" НЕ действует

**ФЗ-289 "О платформенной экономике" (с 01.10.2026):**

- Обязательная верификация продавцов через ЕГРЮЛ/ЕГРИП
- Уведомление об изменении комиссий за 45 дней
- Запрет одностороннего изменения комиссий
- Скидки/акции — уведомление продавца за 5 рабочих дней, право отказа
- Хранение договоров 3+ года

**Необходимые документы:**

1. Публичная оферта для покупателей
2. Агентский договор-оферта для продавцов
3. Пользовательское соглашение
4. Политика конфиденциальности (ФЗ-152)
5. Политика возврата товара
6. Регистрация в Роскомнадзоре как оператор ПД

### Финансовая модель

**Комиссия:**

- Стартовая ставка: 15-20% (ниже WB 34.5%, Ozon 13-43%, Lamoda 37%)
- Комиссия считается от цены товара БЕЗ доставки
- Елена Аксянова (владелец): commissionRate = 0%
- Индивидуальная комиссия для каждого продавца (настраивается админом)
- При промокодах продавца — комиссия от цены ДО скидки

**ЮKassa: Сплитование платежей:**

- Один платёж покупателя → автоматическое расщепление на продавцов
- Каждый продавец подключён к ЮKassa (ИП/ООО, получает свой `account_id`)
- `capture: false` — двухстадийный платёж (холд до подтверждения)
- Холд максимум 7 дней (ограничение ЮKassa)

**Escrow-модель (собственная):**

```
Покупатель оплачивает → ЮKassa capture → деньги на счёте площадки
→ Продавец отправляет (tracking) → Покупатель подтверждает получение
→ protectionEndsAt = deliveredAt + 7 дней
→ Если нет возврата → Payout продавцу / Если возврат → Refund покупателю
```

**Выплаты продавцам (ручной запрос):**

- Продавец создаёт PayoutRequest на доступную сумму из SellerBalance
- Для самозанятых (НПД): **обязательно** приложить чек из "Мой налог" (фото/скриншот)
- Для ИП/ООО: чек опционален, но рекомендован для учёта
- Админ проверяет чек → одобряет → выполняет банковский перевод
- Минимальная сумма: 1000 руб
- Резерв на возвраты: 10% удерживается на 30 дней
- Новые продавцы (первые 90 дней): резерв 20%

**Чеки и налогообложение:**

- Модель Seller хранит `taxSystem`: ИП (УСН/ОСНО/патент), ООО, самозанятый (НПД)
- Платформа выдаёт чек покупателю через ККТ (54-ФЗ) как агент с ИНН продавца
- Самозанятый формирует чек в "Мой налог" на сумму выплаты (НПД 6% для юрлиц)
- ЮKassa с 29.12.2025 **не поддерживает** автоотправку чеков самозанятых
- В будущем: API "Мой налог" (ФНС партнёрское API) или сервисы Робочеки/Консоль
