## Быстрый старт

```bash

nx dev pravda

# Проверки
nx format pravda           # Форматирование (dprint)
nx lint pravda             # Линтинг (oxlint → ESLint)
nx typecheck:tsgo pravda   # Проверка типов (tsgo)

# Тесты
nx test pravda
```
