## [0.3.0] - 2026-10-06

### Added

- Список заметок и кнопка «Новая заметка»
- Редактор Markdown с предпросмотром, сохранение по кнопке и Ctrl+S, защита от закрытия с несохранённым текстом
- Каждое сохранение — новая неизменяемая версия; без изменений версия не создаётся
- История версий: построчное сравнение двух версий («Было» / «Стало») и откат (новая версия со старым текстом)
- Мягкое удаление заметки
- Защита от перезаписи: если заметку изменили с другого устройства, сохранение отклоняется (ветки появятся на этапе 3)

## [0.2.0] - 2026-10-05

### Added

- Схема БД: заметки, неизменяемые версии, рубрики, таблицы Better Auth; миграция `init`
- Вход через Ключницу только для владельца (`OWNER_EMAIL`), страница `/login`, защита страниц `requireOwner()`
- Стартовые рубрики: Веб-архитектор, Поэт, Аудиофил, Синефил, Отаку
