## [0.4.1] - 2026-10-06

### Added

- Деплой на staging: `Dockerfile.production`, `docker-compose.staging.yml` (Postgres + приложение за Traefik), `.env.staging.enc` (SOPS), `output: 'standalone'`

## [0.4.0] - 2026-10-06

### Added

- Офлайн-режим: правка сначала пишется в очередь на устройстве (IndexedDB), затем уходит на сервер; без сети остаётся в очереди и отправляется сама, когда сеть вернулась
- Индикатор «Офлайн / ждут отправки» в углу экрана
- Service worker (`public/sw.js`, без зависимостей): страницы — сначала сеть, при отказе последняя копия; статика Next — из кэша; страница «Нет сети»
- Ветки версий: правка от устаревшей версии (например, сделанная офлайн) сохраняется отдельной веткой и ничего не затирает
- Слияние веток на странице истории: разница, выбор текста (основная / ветка / обе), новая версия с `mergedFromId`

### Changed

- Сохранение больше не отклоняется ошибкой `CONFLICT`: расхождение превращается в ветку
- Миграция `version_merged_from`: поле `NoteVersion.mergedFromId`

## [0.3.0] - 2026-10-06

### Added

- Список заметок и кнопка «Новая заметка»
- Редактор Markdown с предпросмотром, сохранение по кнопке и Ctrl+S, защита от закрытия с несохранённым текстом
- Каждое сохранение — новая неизменяемая версия; без изменений версия не создаётся
- История версий: построчное сравнение двух версий («Было» / «Стало») и откат (новая версия со старым текстом)
- Мягкое удаление заметки
- Защита от перезаписи: если заметку изменили с другого устройства, сохранение отклоняется (ветки появятся на этапе 3)
