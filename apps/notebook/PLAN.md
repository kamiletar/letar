# Блокнот Ками — план разработки

Личный блокнот: версии заметок, откат, офлайн-режим и публикация в рубрики сайта.
Схемы и решения — страница плана: https://claude.ai/artifact/LUsWWH9iycSE4MrkBVrdCZ

## Решения

- PWA, один код с сайтом; заметки офлайн в IndexedDB
- Формат заметки — Markdown с предпросмотром
- Публикация: черновик → «на проверке» → одобрение владельцем
- Вход — через Ключницу, пускаем только `OWNER_EMAIL`
