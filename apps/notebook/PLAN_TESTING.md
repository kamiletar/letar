## Запуск тестов

```bash
nx test notebook             # Unit-тесты (Vitest)
nx e2e notebook-e2e          # E2E-тесты (Playwright), после подключения e2e-suite
```

## Unit-тесты (Vitest)

- `src/lib/outbox.test.ts` (11): очередь отправки — склейка правок, отметка отправленного
- `src/lib/branches.test.ts` (9): головы веток, ветка от устаревшей базы, слияние
- `src/lib/versions.test.ts` (18): новая версия по правке, откат, построчное сравнение, название заметки для списка

## E2E-тесты (Playwright)

Не подключены. Когда появится первая фича, достойная e2e-покрытия:

```bash
nx g @letar/generators:e2e-suite notebook
```

См. `.claude/docs/e2e-testing.md` за особенностями WebKit/Portal-компонентов.
