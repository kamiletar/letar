## Критический путь (MVP)

Минимальный набор фич для запуска:

1. ✅ **Аутентификация** — вход/регистрация пользователей
2. ✅ **Профили** — данные ученика и инструктора
3. ✅ **Связь ученик-инструктор** — приглашения, управление связями
4. ✅ **Расписание и слоты** — настройка рабочего времени, генерация слотов
5. ✅ **Занятия** — создание, подтверждение, отмена
6. ✅ **Проверка пересечений** — защита от двойной записи

## Зависимости по фазам

### Фаза 1 → Фаза 2

| Фаза 1  | Требуется для      |
| ------- | ------------------ |
| Занятия | Предоплата, штрафы |
| Связь   | Баланс             |
| Профили | Уведомления        |

### Фаза 2 → Фаза 3

| Фаза 2      | Требуется для     |
| ----------- | ----------------- |
| Связь       | Передача учеников |
| Уведомления | Telegram-бот      |
| Профили     | Автошколы         |

### Фаза 3 → Фаза 4

| Фаза 3    | Требуется для           |
| --------- | ----------------------- |
| Автошколы | Теор. занятия, экзамены |
| Занятия   | Статистика              |
| Связь     | Мульти-категории        |

### Фаза 4 → Фаза 5

| Фаза 4           | Требуется для    |
| ---------------- | ---------------- |
| Автошколы        | Чаты школы       |
| Занятия          | Рейтинги         |
| Мульти-категории | Поиск            |
| Все фичи         | Панель владельца |
