# Роли пользователей

> Назад к [PLAN.md](../PLAN.md)

## Платформенные роли (UserRole)

| Роль                                  | Описание                                                                    |
| ------------------------------------- | --------------------------------------------------------------------------- |
| **Пользователь (USER)**               | Базовый пользователь. Может записываться на занятия, просматривать каталог. |
| **Инструктор (FREELANCE_INSTRUCTOR)** | Независимый инструктор. Управляет расписанием, ведёт учеников.              |
| **Модератор (MODERATOR)**             | Модерирует контент: отзывы, жалобы, тикеты поддержки.                       |
| **Владелец (OWNER)**                  | Владелец платформы. Полный доступ ко всем функциям.                         |

## Школьные роли (SchoolMemberRole)

| Роль                                         | Описание                                             |
| -------------------------------------------- | ---------------------------------------------------- |
| **Админ (ADMIN)**                            | Полный доступ к школе, включая настройки и удаление. |
| **Менеджер (MANAGER)**                       | Управление школой без настроек.                      |
| **Инструктор (INSTRUCTOR)**                  | Инструктор практики в школе.                         |
| **Преподаватель теории (THEORY_INSTRUCTOR)** | Преподаватель теоретических занятий.                 |
| **Ученик (STUDENT)**                         | Ученик школы.                                        |
