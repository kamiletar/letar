## 🔧 Команды запуска

```bash
# Unit-тесты
nx test driving-school                    # Все unit-тесты
nx test driving-school --watch            # Watch режим

# E2E тесты
nx e2e driving-school-e2e                 # Все E2E тесты
nx e2e driving-school-e2e --headed        # С браузером
nx e2e driving-school-e2e --ui            # Playwright UI
```
