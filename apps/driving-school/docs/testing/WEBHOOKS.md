## Тестовые сценарии

### Сценарий 1: Полный цикл создания и доставки

```
1. ADMIN школы создаёт webhook на https://webhook.site/xxx
2. Выбирает события: LESSON_CONFIRMED, LESSON_CANCELLED
3. Получает секретный ключ whsec_xxx
4. Инструктор подтверждает занятие
5. webhook.site получает POST с подписью
6. Проверяем HMAC подпись с полученным секретом
```

### Сценарий 2: Retry после ошибки

```
1. Webhook настроен на URL который возвращает 500
2. Происходит событие LESSON_COMPLETED
3. Первая попытка → 500 → создаётся retry запись
4. Через 1 минуту → retry → снова 500
5. Через 5 минут → retry → 200 OK
6. Статус меняется на SUCCESS
```

### Сценарий 3: Auto-disable

```
1. Webhook отправляет на недоступный URL
2. 10 подряд неудачных попыток
3. Webhook автоматически переходит в статус DISABLED
4. ADMIN получает уведомление
5. ADMIN может вручную активировать обратно
```

## Mock сервер для тестов

Для E2E тестов используется webhook.site или локальный mock:

```typescript
// fixtures/webhook-mock-server.ts
import { createServer } from 'http'

export function createWebhookMockServer(port: number) {
  const requests: { headers: Headers; body: unknown }[] = []

  const server = createServer((req, res) => {
    let body = ''
    req.on('data', (chunk) => (body += chunk))
    req.on('end', () => {
      requests.push({
        headers: req.headers,
        body: JSON.parse(body),
      })
      res.writeHead(200)
      res.end('OK')
    })
  })

  server.listen(port)

  return {
    getRequests: () => requests,
    close: () => server.close(),
  }
}
```
