# E2E Testing Plan: Calendars

**Версия:** 0.194.0
**Дата:** 2026-01-19
**Статус:** Планирование

## Обзор

Тестирование календарной интеграции:

- **Phase 1:** iCal feed подписка (readonly URL)
- **Phase 2:** Google Calendar API (двусторонняя синхронизация)

## Scope

### Phase 1 (v0.194.0)

- iCal Feed генерация
- API endpoint `/api/calendar/feed/[token]`
- UI страницы настроек календаря
- Настройки контента feed

### Phase 2 (v0.194.0)

- Google Calendar OAuth
- Список календарей пользователя
- Подключение/отключение календарей
- Настройки направления синхронизации
- Ручной запуск синхронизации

### Вне scope (Phase 3)

- Yandex Calendar CalDAV
- Apple Calendar (iCloud)
- Автоматическая фоновая синхронизация
- Push notifications от Google
