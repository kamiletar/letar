## 1. Аутентификация

- Регистрация: email + пароль или OAuth (Google, Яндекс)
- При регистрации: email, пароль, имя, роль (ученик/инструктор)
- Подтверждение email, восстановление пароля (ссылка 1 час)

## 2. Профили

- **Ученик:** фото, имя, телефон, районы, заметка для инструктора
- **Инструктор:** фото, имя, телефон, авто (марка, модель, госномер, КПП), bio, стаж, категории прав

## 3. Связь ученик-инструктор

- Приглашение: QR-код или email (срок 7 дней)
- Статусы связи: ACTIVE, PAUSED, DISCONNECTED
- Атрибуты: isPrimary, баланс, статистика занятий
- Передача ученика другому инструктору (временная/постоянная)

## 4. Расписание инструктора

- Настройки: рабочие дни, время, длительность занятия, перерывы
- Горизонт планирования: 1-30 дней вперёд
- Кастомные перерывы: регулярные (обед) и разовые
- Автоматическая генерация слотов со статусом AVAILABLE
- Ручное управление: блокировка/разблокировка слотов

## 5. Занятия

**Статусы:** PENDING → CONFIRMED → COMPLETED / NO_SHOW / CANCELLED / RESCHEDULED

**Ограничения:**

- Ученик не может записаться на два занятия в пересекающееся время (даже у разных инструкторов)
- Проверка при создании и подтверждении занятия

**Создание:**

- Ученик выбирает слот → статус PENDING → инструктор подтверждает
- Инструктор создаёт → статус PENDING или CONFIRMED (автоподтверждение)

**Отмена:**

- Фиксируется: кто, когда, причина, время до занятия
- Дедлайн отмены без штрафа (настраивается инструктором)

**Перенос:**

- Старое занятие → RESCHEDULED + ссылка на новое
- Новое занятие → CONFIRMED

## 6. Финансы

- **Баланс:** предоплаченные занятия (лимит 50), списание при COMPLETED/NO_SHOW
- **Штрафы:** LATE_CANCEL, NO_SHOW, отмена с причиной, отметка оплаты

## 7. Отсутствие инструктора

- Типы: VACATION (с датой окончания), SICK_LEAVE (без даты)
- При создании: блокировка слотов, пометка занятий NEEDS_RESCHEDULE
- Возвращение: разблокировка слотов, уведомления

## 8. Школы вождения

- Создание школы (создатель = админ)
- Роли: ADMIN, MANAGER, INSTRUCTOR, THEORY_INSTRUCTOR, STUDENT
  - **ADMIN** — полный доступ к школе
  - **MANAGER** — как админ, но без: редактирования информации о школе, назначения менеджеров, удаления школы
  - **INSTRUCTOR** — инструктор практики
  - **THEORY_INSTRUCTOR** — преподаватель теории
  - **STUDENT** — ученик школы
- Приглашения по email или ссылке (срок 7 дней)
- Админ: управление членами, расписанием, занятиями, статистикой

## 9. Уведомления

- **Каналы:** Push, Email, Telegram
- **Типы:** занятия (создание, подтверждение, отмена, напоминание), штрафы, приглашения, передачи
- **Telegram-бот:** /start, /lessons, /schedule, /help, inline-кнопки

## 10. Оффлайн-режим (PWA)

- **Кэшируется:** профиль, список контактов, расписание на неделю
- **Очередь:** запись, отмена, подтверждение → синхронизация при онлайн
- **Недоступно:** настройки, управление профилем, приглашения

> Подробнее: [OFFLINE.md](./OFFLINE.md)

## 11. Мульти-категории прав

**Все категории РФ:**

- **M** — мопеды, скутеры
- **A1, A** — мотоциклы (лёгкие / все)
- **B1, B** — квадрициклы / легковые авто
- **C1, C** — грузовики (средние / тяжёлые)
- **D1, D** — автобусы (малые / большие)
- **BE, CE, C1E, DE, D1E** — с прицепом
- **Tm, Tb** — трамваи, троллейбусы

**Применение:**

- **Школа:** поле `licenseCategories` — какие категории преподаёт школа
- **Связь ученик-инструктор:** поле `category` — на какую категорию учится ученик
- **Занятие:** поле `category` — для какой категории занятие
- **Ученик может:** учиться на B у одного инструктора и на C у другого

## 12. Типы занятий и прайс-лист

**Инструктор создаёт типы занятий:** название, описание, цена, длительность

**Примеры типов:**

- Стандартное занятие — 2000₽ / 90 мин
- Экстремальное вождение — 5000₽ / 120 мин
- Контраварийная подготовка — 4000₽ / 90 мин
- Маршрут экзамена ГИБДД — 2500₽ / 60 мин
- Вождение по городу — 2200₽ / 90 мин

**Применение:**

- При записи ученик выбирает тип занятия
- Слот может иметь ограничение по типам
- Статистика доходов по типам занятий

## 13. Теоретические занятия

**Групповые занятия для школ:**

- Учебные группы: утренняя, вечерняя, выходного дня
- Ученик выбирает группу при поступлении
- Расписание группы на весь курс (например, 2 месяца)

**Темы занятий:**

- ПДД, знаки, первая помощь, устройство авто и т.д.
- Посещаемость: отметка присутствия учеников
- Прогресс ученика: сколько тем пройдено

**Изменения расписания:**

- Школа может перенести/отменить занятие
- Автоматическое уведомление всех учеников группы

## 14. Экзамены

**Типы экзаменов:**

- Внутренний теоретический (в школе)
- Внутренний практический (площадка + город)
- ГИБДД теория
- ГИБДД практика (площадка)
- ГИБДД практика (город)

**Цепочка допуска:**

```
Теория курса → Внутр. теория → Внутр. практика → ГИБДД теория → ГИБДД практика
     ↓              ↓                ↓                 ↓              ↓
 все темы      экзамен сдан     экзамен сдан      экзамен сдан   ПРАВА!
```

**Функции:**

- Расписание экзаменов, лимит мест
- Платные услуги: сопровождение, аренда авто, пересдача
- Госпошлина: отметка оплаты, история платежей
- Результаты: сдал / не сдал / неявка

## 15. Чаты платформы

**Типы чатов:**

- **PRIVATE** — тет-а-тет между двумя пользователями
- **INSTRUCTORS** — все инструкторы платформы
- **STUDENTS** — все ученики платформы
- **SCHOOL** — все члены конкретной школы
- **STUDY_GROUP** — участники учебной группы
- **GENERAL** — все пользователи платформы

**Функции:** текст, вложения, цитирование, реакции, редактирование, удаление

## 16. Связь с поддержкой

- Кнопка «Написать разработчику» в профиле/настройках
- Темы обращений: помощь, баг, предложение, другое
- Чат с поддержкой: история переписки, статус обращения
- Статусы тикетов: открыт, в работе, решён, закрыт

## 17. Панель владельца

- **Роль OWNER:** назначается через БД или env-переменную
- **Статистика платформы:** пользователи, школы, занятия, активность
- **Управление пользователями:** просмотр, блокировка, смена роли
- **Управление школами:** просмотр всех школ, модерация
- **Входящие обращения:** ответы пользователям, статусы тикетов
- **Логи и аудит:** важные действия на платформе

## 18. Договор-оферта и монетизация

**Договор-оферта:**

- Публичная оферта на сайте
- Принятие при регистрации (чекбокс)
- OAuth: экран принятия оферты перед созданием аккаунта
- Версионирование, политика конфиденциальности

**Этапы монетизации:**

1. **Сейчас:** всё бесплатно
2. **Потом:** платные тарифы для инструкторов и школ

**Тарифы (в будущем):**

| Тариф      | Цена                  | Описание                               |
| ---------- | --------------------- | -------------------------------------- |
| Ученик     | Бесплатно навсегда    | Поиск инструкторов, запись, расписание |
| Инструктор | X₽/мес                | Независимые инструкторы                |
| Школа      | Y₽/мес за инструктора | Расширенные функции                    |

## 19. Поиск инструктора и школы

**Каталоги:** инструкторы, школы

**Фильтры поиска:**

- Категория прав (A, B, C, D...)
- Тип занятия, район/город
- Рейтинг и отзывы
- Цена, тип КПП
- На чьей машине (инструктора / ученика)

**Профили:**

- Инструктор: фото, bio, стаж, цены, рейтинг, слоты
- Школа: логотип, описание, адрес, курсы, инструкторы

## 20. Оптимизация для мобильных

**Адаптивный дизайн:**

- Mobile-first подход
- Breakpoints: mobile / tablet / desktop

**Тач-интерфейс:**

- Увеличенные области нажатия (min 44px)
- Свайпы, pull-to-refresh, жесты

**Производительность:**

- Ленивая загрузка, виртуализация списков
- Минимизация перерисовок

**Нативные возможности:**

- Вибрация, камера (QR-код), геолокация

## 21. Рейтинги и отзывы

**Кто оценивает:**

- Ученик → инструктора (после занятия)
- Ученик → школу (после обучения)

**Оценка:** 1–5 звёзд + текстовый отзыв

**Модерация:**

- Автофильтр нецензурной лексики
- Жалоба на отзыв
- Ответ инструктора/школы

**Защита от накрутки:**

- Только реальные ученики
- Один отзыв на занятие/курс
