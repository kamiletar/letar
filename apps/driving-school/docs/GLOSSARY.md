## Основные термины

| Термин                    | Описание                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------- |
| **Слот (TimeSlot)**       | Временной интервал в расписании инструктора. Статусы: AVAILABLE, BOOKED, BLOCKED         |
| **Занятие (Lesson)**      | Запись ученика на слот. Статусы: PENDING → CONFIRMED → COMPLETED / NO_SHOW / CANCELLED   |
| **Связь (Connection)**    | Отношение между учеником и инструктором. Содержит баланс, статистику, настройки          |
| **Баланс**                | Количество предоплаченных занятий ученика у конкретного инструктора (макс. 50)           |
| **Штраф (Penalty)**       | Начисление за позднюю отмену (LATE_CANCEL) или неявку (NO_SHOW)                          |
| **Передача (Transfer)**   | Перенос ученика от одного инструктора к другому. Типы: TEMPORARY, PERMANENT              |
| **Отсутствие (Absence)**  | Период недоступности инструктора. Типы: VACATION (с датой), SICK_LEAVE (без даты)        |
| **Автошкола (School)**    | Организация, объединяющая инструкторов и учеников. Роли: ADMIN, INSTRUCTOR, STUDENT      |
| **Приглашение**           | Механизм добавления пользователей: в связь (7 дней) или в школу (7 дней)                 |
| **PWA**                   | Progressive Web App — веб-приложение с возможностью установки и оффлайн-работы           |
| **Горизонт планирования** | Количество дней вперёд, на которые генерируются слоты (1-30 дней)                        |
| **Дедлайн отмены**        | Время до занятия, после которого отмена считается поздней и влечёт штраф (настраивается) |
| **isPrimary**             | Флаг основного инструктора у ученика (для уведомлений и приоритетов)                     |

## Статусы занятий

| Статус        | Описание                                           |
| ------------- | -------------------------------------------------- |
| `PENDING`     | Ожидает подтверждения инструктором                 |
| `CONFIRMED`   | Подтверждено, занятие состоится                    |
| `COMPLETED`   | Занятие проведено успешно                          |
| `NO_SHOW`     | Ученик не явился                                   |
| `CANCELLED`   | Отменено (учеником или инструктором)               |
| `RESCHEDULED` | Перенесено на другое время (создано новое занятие) |

## Статусы слотов

| Статус      | Описание                  |
| ----------- | ------------------------- |
| `AVAILABLE` | Свободен для записи       |
| `BOOKED`    | Занят (есть занятие)      |
| `BLOCKED`   | Заблокирован инструктором |

## Статусы связи

| Статус         | Описание                           |
| -------------- | ---------------------------------- |
| `ACTIVE`       | Активная связь, можно записываться |
| `PAUSED`       | Приостановлена (временно)          |
| `DISCONNECTED` | Разорвана, нельзя записываться     |

## Типы штрафов

| Тип           | Описание                        |
| ------------- | ------------------------------- |
| `LATE_CANCEL` | Поздняя отмена (после дедлайна) |
| `NO_SHOW`     | Неявка на занятие               |

## Типы отсутствия

| Тип          | Описание                      |
| ------------ | ----------------------------- |
| `VACATION`   | Отпуск с датой окончания      |
| `SICK_LEAVE` | Больничный без даты окончания |

## Школьные роли

| Роль                | Описание                |
| ------------------- | ----------------------- |
| `ADMIN`             | Полный доступ к школе   |
| `MANAGER`           | Управление без настроек |
| `INSTRUCTOR`        | Инструктор практики     |
| `THEORY_INSTRUCTOR` | Преподаватель теории    |
| `STUDENT`           | Ученик школы            |

| C         | Тяжёлые грузовики          |

| D         | Большие автобусы           |

| C1E       | Средние грузовики + прицеп |
| DE        | Автобусы с прицепом        |
| D1E       | Малые автобусы + прицеп    |
| Tm        | Трамваи                    |
| Tb        | Троллейбусы                |
