# Changelog

Все изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование следует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.64.0] - 2025-12-09

### Добавлено

- **Фотографии филиалов** — полноценная система управления изображениями
  - Модели `Image` и `LocationImage` для централизованного хранения изображений
  - API роуты `/api/upload/locations` для загрузки, удаления и сортировки фото
  - API роут `/api/files/[...path]` для отдачи загруженных файлов
  - Библиотека `@/lib/images` с функциями для работы с изображениями
  - Компонент `LocationImages` с drag-and-drop сортировкой (@dnd-kit)
  - Кнопка "Фото" на карточке филиала с бейджем количества изображений
  - Диалог управления фотографиями с превью, загрузкой и удалением

## [0.63.2] - 2025-12-09

## [0.63.0] - 2025-12-09

### Исправлено

- **Описания категорий водительских прав** — приведены в соответствие с официальными
  - M: Мопеды, скутеры (до 50 см³)
  - A1: Лёгкие мотоциклы (до 125 см³)
  - A: Мотоциклы (более 125 см³)
  - B1: Трициклы, квадрициклы (НЕ коробка автомат!)
  - B: Легковые авто (до 3.5т)
  - C1: Средние грузовики (3.5–7.5т)
  - C: Грузовые авто (более 3.5т)
  - D: Автобусы (более 8 мест)
