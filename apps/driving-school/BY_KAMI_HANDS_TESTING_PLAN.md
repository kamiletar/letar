## Порядок тестирования

План организован по **зависимостям** — каждый следующий раздел требует выполнения предыдущих.

**Легенда статусов:**

- ⬜ Не проверено
- ✅ Пройдено
- ❌ Найден баг (требует исправления)
- 🔧 Исправлено, требует повторной проверки
- ⏭️ Пропущено (не актуально)

## Gotchas / Подводные камни

> Особенности, которые могут сбить с толку при тестировании

| #   | Проблема                                         | Решение                                                       |
| --- | ------------------------------------------------ | ------------------------------------------------------------- |
| 1   | Изменения кода не применяются                    | SW кэширует JS. Сделай Clear Site Data + жёсткую перезагрузку |
| 2   | Форма валидируется при вводе хотя не должна      | Скорее всего SW отдаёт старый код. См. п.1                    |
| 3   | Для чистого теста — отключи SW                   | `NEXT_PUBLIC_DISABLE_SERVICE_WORKER=true` в `.env.local`      |
| 4   | После отключения SW нужен перезапуск dev сервера | Переменные инлайнятся при сборке                              |
| 5   | Nginx Proxy Manager кэширует статику             | sw.js должен иметь `Cache-Control: no-cache` (см. ниже)       |
| 6   | Апдейты "залипают" — новая версия не грузится    | Проверь что sw.js не кэшируется на nginx + версия в sw.js     |

### Nginx + SW: как избежать "залипания" обновлений

**Проблема:** Nginx Proxy Manager кэширует статику включая `sw.js`, из-за чего браузер не видит обновлений.

**Решение:**

1. **В nginx** — добавить правило для sw.js:

   ```nginx
   location = /sw.js {
     add_header Cache-Control "no-cache, no-store, must-revalidate";
     add_header Pragma "no-cache";
     add_header Expires "0";
   }
   ```

2. **В Next.js** — добавить headers в `next.config.ts`:

   ```typescript
   async headers() {
     return [
       {
         source: '/sw.js',
         headers: [
           { key: 'Cache-Control', value: 'no-cache, no-store, must-revalidate' },
         ],
       },
     ]
   }
   ```

3. **Версионирование SW** — добавить версию в sw.js:
   ```javascript
   const SW_VERSION = 'v1.2.3' // менять при деплое
   ```
