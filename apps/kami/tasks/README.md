# Очередь задач Kami

Личный сайт-портфолио (Next.js 16, Chakra UI v3, Keystatic, ZenStack): «Обо мне», блог, консалтинг,
аудиоплеер с визуализациями (Butterchurn, Hydra), тест личности, кросс-постинг в соцсети, админка.
Вход через Ключницу. Приложение лежит в публичном корне монорепо, не в submodule (KM-003).

## Старт

`bun scripts/tasks.mjs next kami` из корня letar. Затем `show KM-NNN`,
`start KM-NNN --owner kami-dev`, `note`, `done --summary`.
Формат: [tasks-per-file](/.claude/docs/tasks-per-file.md). Статусы живут только в шапках задач.

## Текущий фокус

- **KM-012** — минималистичная посадочная с визитки: контакты, заказ сайта и главное меню.
- **KM-015–KM-019** — прототипы динамики букв, заставка и портрет; исследование в KM-014.
- **KM-021–KM-022** — реализация друзей и преимуществ; спецификация в KM-020,
  вопросы владельцу — KM-024.
- Студия: ST-066–ST-068 — портфолио, CRT-вход и Back/reload, связаны через KM-023.
- **KM-002** — текст «Обо мне»: ждёт утверждённую редакцию владельца.
- Ручная проверка владельца: вход (KM-004).
- Список ожиданий: `bun scripts/tasks.mjs waiting kami --on kami`.

## Правила

1. Нет ответа в планах и решение не твоё — `tasks new … --status blocked --blocked-by "kami: …"`
   и бери следующую.
2. Без слова владельца: `git push`, `bun install` и `bun.lock`, deploy-request.
3. Публичный репозиторий: личные тексты и биографию в файлы задач и журнал не переносить,
   ссылаться на `.claude/private/`. Домены, реквизиты и персональные данные — нельзя.
4. Один пункт — один коммит: версия в `package.json`, запись в `CHANGELOG.md`, перед коммитом
   `format`, `lint`, `typecheck:tsgo`.
