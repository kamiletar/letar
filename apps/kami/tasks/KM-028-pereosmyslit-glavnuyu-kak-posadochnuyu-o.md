## Что и зачем

Главная Kami должна впечатлять нового посетителя так же, как входы студии, но своим сюжетом из букв.
Одновременно у сайта появляется один главный оффер «Заказать сайт». Это общая спецификация:
реализация разбита на KM-029–KM-033, порядок повтора входа — в KM-018.

## Решения владельца (2026-10-26)

| Вопрос                | Решение                                                                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Главный CTA           | «Заказать сайт»                                                                                                                                        |
| Вход                  | Многоэкранная церемония: boot kami.os → сборка имени → стартовое меню игры                                                                             |
| Экран «Выберите путь» | Это и есть главное меню: отдельного шага с выбором роли нет, выбор пункта сразу ведёт в раздел                                                         |
| Boot                  | Буквы «собирают систему»: строки загрузки с честными статусами, затем KAMI. Не копия BIOS студии                                                       |
| Повтор                | Полная церемония — при первом заходе; потом короткая (~1,5 с); Back — без входа                                                                        |
| Структура             | Главная остаётся хабом. «Заказать сайт» ведёт на свою посадочную `/site/`, она — в заявку студии                                                       |
| Трафик                | QR с визитки и рекомендации: почти всегда телефон, человек уже знает Kami                                                                              |
| Заказчики             | Знакомые и друзья                                                                                                                                      |
| Условия на посадочной | Цена «от» и сроки, скидка друзьям, бесплатный первый разговор, оплата по этапам                                                                        |
| Доказательства        | Проекты из админки с флагом `featured`; цифры считаются из данных; пустой блок не показывается                                                         |
| Финальная кнопка      | Заявка студии `?topic=site&from=kami`, одна воронка заявок                                                                                             |
| Фото владельца        | Три места: фото в hero `/site/`; превью ссылки с лицом (главная и `/site/`); портрет из букв как шаг полной церемонии, если прототип KM-019 понравится |

Вывод для текста: посетитель уже доверяет лично. Посадочной не нужно убеждать незнакомца —
ей нужно быстро ответить «сколько, как долго, как идёт работа, что если не понравится».
Поэтому по навыку выбран тип **C (минимальная страница конверсии)** с элементами типа A:
короткий hero, условия, tagline, три шага, проекты, FAQ, финальный CTA.

## Карта

```
QR / ссылка ──► /  (главная-хаб)
                 │  первый заход: церемония ~4,2 с │ повтор: ~1,5 с │ Back: без входа
                 ▼
        ▶ Заказать сайт ──► /site/ ──► заявка студии (?topic=site&from=kami)
          Обо мне       ──► /about/
          Блог          ──► /blog/
          Контакты      ──► /contacts/
          Для друзей    ──► /#friends
```

## Церемония (KM-030, KM-031)

Таймлайн полной версии. Времена — бюджет прототипа, не ожидание загрузки.

| Время, с | Что видно                                                                                           | Чем доказано     |
| -------- | --------------------------------------------------------------------------------------------------- | ---------------- |
| 0–0,4    | Потоки букв проявляются (механика KM-017)                                                           | время            |
| 0,4–2,0  | Boot-лог: `kami.os 0.39.0`, `глифы … ok`, `шрифты … ok`, `язык … ru`, `тема … тёмная`               | реальные события |
| 2,0–3,0  | Буквы потока ловятся на места и складывают KAMI; лог гаснет вверх                                   | время            |
| 3,0–3,6  | Печатается роль с курсором                                                                          | время            |
| 3,6–4,2  | Пункты меню проявляются по очереди (шаг 60 мс), ▶ на «Заказать сайт»; фон успокаивается вокруг меню | время            |

С портретом (KM-019, только после одобрения владельцем на телефоне): между boot-логом и KAMI
лицо проступает из падающих букв (2,0–3,2 с), рассыпается, и его буквы летят в имя;
полная версия становится ~5,2 с.

Короткая версия (~1,5 с): проявление потоков, быстрая сборка KAMI без лога, меню, успокоение фона.

Общие требования:

- Имя, роль и меню приходят серверным HTML на финальных местах. Анимация меняет только
  прозрачность и `transform`, раскладка не прыгает (CLS < 0,1).
- Без JS — сразу финальный кадр. Если JS завис, CSS-страховка показывает меню через 5 с.
- Reduced-motion — сразу финальный кадр. «Пропустить» и Escape — конец за ≤0,6 с.
  Клик по пустому месту тоже завершает церемонию, но никуда не переходит.
- Строка лога появляется только после реального события (`warm()` атласа, `document.fonts.ready`).
  Нет события за 2,5 с — строка пишет «позже», церемония идёт дальше, меню не ждёт.
- Слои церемонии `aria-hidden`; фокус не перехватывается; звука нет.

## Посадочная `/site/` (KM-029, KM-032, KM-033)

1. **Hero.** Заголовок и подзаголовок (черновики ниже), CTA «Обсудить сайт», строка доказательства
   из реальных данных (число избранных проектов, цена «от», если задана). Рядом — настоящее фото
   владельца: знакомому посетителю лицо сразу говорит «это тот самый Kami». Превью ссылки (`og:image`)
   главной и `/site/` — фото, KAMI и строка на языке локали.
2. **Условия.** Карточки: цена «от», сроки «от», бесплатный первый разговор, оплата по этапам,
   скидка друзьям со ссылкой на `/#friends`. Карточка с незаданной цифрой не выводится.
3. **Tagline** с пословной подсветкой при прокрутке (B11 навыка), минимум две строки.
4. **Как идёт работа** — три шага.
5. **Проекты** — избранные из админки; нет ни одного — секции нет.
6. **FAQ** — 6–8 вопросов, ответы утверждает владелец (KM-033); FAQ schema.
7. **Финальный CTA** — тот же, что в hero.

Черновики текста (утверждает владелец):

- Заголовок: «Сделаю сайт для вашего дела. От первого разговора до запуска»
- Подзаголовок: «Первый разговор бесплатно, оплата по этапам, друзьям скидка. Вы видите каждый шаг»
- CTA: «Обсудить сайт»
- Tagline: «Вы рассказываете, чем занимаетесь. / Я делаю сайт, который объясняет это за вас»
- Шаги: «Разговор — бесплатно разбираем задачу и бюджет» → «Этапы — платите за каждый сданный этап» →
  «Запуск — сайт работает, правки и поддержка по договорённости»
- FAQ: сколько стоит; сколько по времени; что нужно от меня; можно ли править сайт самому;
  домен и хостинг; кто поддерживает после запуска; что если результат не нравится; кому положена скидка

Визуальная система: шрифт, токены, стекло и буквенный фон Kami сохраняются (адаптация навыка для
Letar). Из навыка берутся: ширина hero ≤680 px, `text-wrap: balance/pretty`, шкала размеров,
кривая `cubic-bezier(0.22,1,0.36,1)`, появление секций через IntersectionObserver, полный набор
состояний кнопок, без выдуманных отзывов и цифр. Фон на `/site/` — спокойный, без церемонии.

## Измерения

События Umami через `trackEvent` из `@letar/analytics`: `entry-complete`, `entry-skip`,
`menu-select` (с ключом пункта), `site-cta` (hero или финал). Рост заявок не обещаем:
сравнение «до/после» — по этим событиям после деплоя.

## Порядок и зависимости

```
KM-029 посадочная /site/ ─┬─► KM-031 игровое меню (ведёт на /site/) ──► KM-018 повтор
KM-030 церемония ─────────┘
KM-029 ──► KM-032 проекты на посадочной
KM-030 ──► KM-019 портрет из букв (за флагом, решение владельца по прототипу)
KM-033 цифры владельца ──► заполнение карточек условий и FAQ (без кода)
```

KM-029 и KM-030 можно делать параллельно: разные файлы (`[locale]/site/**` против
`matrix-scene.ts`/`matrix-rain.tsx`/`hero/**`). KM-031 трогает `hero.tsx` и `public-navigation.ts` —
только после KM-030.
