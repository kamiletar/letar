## Что и зачем

Keystatic в браузере выбирал local по недоступному приватному env, хотя API выбирал GitHub.
Запрос дерева возвращал текстовый 404, и коллекция не открывалась.

## Приёмка

- Браузер получает режим от сервера без передачи секретов.
- GitHub и local используют соответствующие пути контента.
- Повторный рендер не пересоздаёт страницу редактора.

## План

1. Вынести конфигурацию в фабрику с явным режимом.
2. Передавать режим из динамического server layout, разделить серверное чтение env и клиент.
3. Проверить регрессию тестами, форматирование, lint и typecheck.
