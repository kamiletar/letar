# Локальные шрифты

JetBrains Mono лежит здесь файлом и подключается через `next/font/local` в
[`../[locale]/layout.tsx`](../[locale]/layout.tsx).

## Почему не `next/font/google`

`next/font/google` скачивает шрифты при **каждой** сборке — хрупкость загрузчика, разбор случая с
падением на domwellbes 2026-09-22 — `apps/domwellbes/src/app/fonts/README.md`. Сборка больше не
ходит в сеть за шрифтами.

## Что внутри

| Файл                                 | Гарнитура      | Ось `wght` | Размер |
| ------------------------------------ | -------------- | ---------- | ------ |
| `JetBrainsMono-cyrillic-latin.woff2` | JetBrains Mono | 100–700    | 56 КБ  |

Variable-шрифт, ось `wght` ограничена диапазоном 100–700 — реально используемый разброс
`fontWeight` в приложении (от `100` в подписях до `bold`/`600` в кнопках и активном пункте
`locale-switcher.tsx`; `800` нигде не используется).

Лицензия — SIL Open Font License 1.1, текст рядом: `OFL-JetBrainsMono.txt`.

## Покрытие символов — приложение на 40 локалей

`time` — единственное приложение с `next-intl` на **40 локалей** (`ALL_LOCALES` в
`src/i18n/routing.ts`), включая 4 RTL (ar, fa, he, ur). Прежний `subsets` у `next/font/google`
был `['cyrillic', 'latin', 'latin-ext', 'greek', 'vietnamese']` **без** `weight` (Next скачивал
полный variable-диапазон). Субсет здесь — те же пять диапазонов Google Fonts дословно (сняты с
`fonts.googleapis.com/css2?family=JetBrains+Mono`, не переиспользованы обобщённые latin/cyrillic
других шрифтов — точные unicode-range отличаются по шрифтам), плюс явная проверка, какие из 40
локалей реально покрываются.

### Какие локали покрыты шрифтом, а какие — нет

**JetBrains Mono — латинско-кириллическо-греческий монопространственный шрифт. Google Fonts не
предлагает для него ни CJK, ни арабский, ни иврит, ни армянский, ни грузинский, ни деванагари,
ни тайский, ни тамильский/телугу subset — этих скриптов у шрифта нет физически**, ни в вырезке,
ни в полном невырезанном файле (проверено скачиванием и `cmap`). Значит для соответствующих
локалей браузер **и раньше**, под `next/font/google`, рисовал текст через системный
fallback-шрифт — переход на `next/font/local` ничего не меняет для них, это не регрессия:

| Локали без глифов в JetBrains Mono (fallback на системный шрифт — было так и раньше) |
| ------------------------------------------------------------------------------------ |
| `ja` 日本語, `zh` 中文, `ko` 한국어 — CJK/Hangul                                     |
| `ar` العربية, `fa` فارسی, `ur` اردو — арабский                                       |
| `he` עברית — иврит                                                                   |
| `hy` Հայերեն — армянский                                                             |
| `ka` ქართული — грузинский                                                            |
| `hi` हिन्दी, `mr` मराठी — деванагари                                                  |
| `bn` বাংলা — бенгальский                                                             |
| `ta` தமிழ், `te` తెలుగు — тамильский/телугу                                            |
| `th` ภาษาไทย — тайский                                                               |

Реально покрытые латиницей/кириллицей/греческим/вьетнамским локали (32 из 40) — стандартные
диапазоны `latin`+`latin-ext`+`cyrillic`+`greek`+`vietnamese`, идентичные прежнему поведению.

### Известный, не новый пробел: Қ/ҷ/ӣ в `locale-switcher.tsx`

Нативные названия `kk: 'Қазақша'` и `tg: 'Тоҷикӣ'` содержат буквы казахского/таджикского
алфавита за пределами базового блока Cyrillic (U+0400–045F): Қ/қ (049A/049B), ҷ (04B7), ӣ (04E3).
Они лежат в блоке Cyrillic Extended-B (0460–052F, Google-субсет `cyrillic-ext`) — **JetBrains
Mono в google/fonts его не предлагает, и этих глифов нет даже в полном невырезанном файле**
(проверено `cmap`, как и с недостающими скриптами выше). Прежний `next/font/google` тоже не
запрашивал `cyrillic-ext` — те же три буквы уже рисовались через fallback. Не регрессия, не
новый пробел; чинится только сменой гарнитуры для этих строк, вне скоупа этой миграции.

Остальные 8 локалей, использующих нестандартные для чистой кириллицы буквы, покрыты полностью:
`uz: Oʻzbekcha` (ʻ = U+02BB, уже в блоке `latin`), `tk: Türkmençe`/`az: Azərbaycanca` (ü/ç/ə — в
`latin`/`latin-ext`), `uk`/`be`/`ky` — чистая кириллица без спецбукв.

### Вне скоупа: `src/lib/email-translations.ts`

Переводы транзакционных писем используют арабский/деванагари/CJK/доп. кириллицу массово (78 из
257 найденных сканером символов) — письма рендерятся HTML-почтой со своим шрифтовым стеком, к
веб-шрифту сайта отношения не имеют (тот же принцип, что и в `driving-school`/`dsperevod`).

Покрытие проверено разбором `cmap`
([font-cmap-coverage-verification](/.claude/docs/font-cmap-coverage-verification.md)).

## Как пересобрать

```bash
python scripts/fonts/subset-google-font.py \
  --slug jetbrainsmono --family-camel JetBrainsMono \
  --weights 100 700 \
  --unicodes \
  "0000-00FF,0131,0152-0153,02BB-02BC,02C6,02DA,02DC,0304,0308,0329,2000-206F,20AC,2122,2191,2193,2212,2215,FEFF,FFFD" \
  "0100-02BA,02BD-02C5,02C7-02CC,02CE-02D7,02DD-02FF,0304,0308,0329,1D00-1DBF,1E00-1E9F,1EF2-1EFF,2020,20A0-20AB,20AD-20C0,2113,2C60-2C7F,A720-A7FF" \
  "0301,0400-045F,0490-0491,04B0-04B1,2116" \
  "0370-0377,037A-037F,0384-038A,038C,038E-03A1,03A3-03FF" \
  "0102-0103,0110-0111,0128-0129,0168-0169,01A0-01A1,01AF-01B0,0300-0301,0303-0304,0308-0309,0323,0329,1EA0-1EF9,20AB" \
  --out apps/time/src/app/fonts/JetBrainsMono-cyrillic-latin.woff2
```

Пять групп диапазонов — latin, latin-ext, cyrillic, greek, vietnamese дословно с
`fonts.googleapis.com/css2?family=JetBrains+Mono`, повторяют прежние `subsets` у
`next/font/google`. Общий скрипт — `scripts/fonts/subset-google-font.py`. Требует
`pip install fonttools brotli`.
