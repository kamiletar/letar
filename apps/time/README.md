# Time

Приложение для управления временем.

## Версия и стек

| Параметр    | Значение           |
| ----------- | ------------------ |
| **Версия**  | 0.1.0              |
| **Порт**    | 3013               |
| **Next.js** | 16.1               |
| **React**   | 19                 |
| **UI**      | Chakra UI v3       |
| **Формы**   | @letar/forms + Zod |

## Быстрый старт

```bash
nx dev time          # Разработка
nx format time       # Форматирование
nx lint time         # oxlint → ESLint
nx typecheck:tsgo time # Проверка типов
nx test time         # Тесты
```
