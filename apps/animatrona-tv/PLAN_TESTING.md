## Unit-тесты (vitest, заведено 2026-09-08)

Покрыта чистая логика, не требующая React Native Testing Library — RN-компоненты (экраны,
`TVRow`/`FocusableCard`/плеер) тестами пока не покрыты, это отдельная будущая задача.

| Файл                                 | Тестов | Что покрыто                                                                                                                                                                                                                  |
| ------------------------------------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/utils/tvStyles.spec.ts`         | 6      | `focusableStyle` — все ветки (фокус/без фокуса, несколько base, `after`)                                                                                                                                                     |
| `src/hooks/usePlayerEpisode.spec.ts` | 12     | Выбор дефолтной аудио/субтитр-дорожки, фоллбэк на первую аудиодорожку (у субтитров фоллбэка нет — асимметрия по дизайну), «эпизод не найден», `Error`/не-`Error` из API, перезапрос при смене `episodeId`, ручной `setError` |
| `src/api/client.spec.ts`             | 3      | Обёртка над `createApiClient` — правильный `getState`, полнота реэкспорта                                                                                                                                                    |
| `src/store/connection.spec.ts`       | 1      | Обёртка над `createConnectionStore` — уникальный `storageKey` для tv                                                                                                                                                         |

`usePlayerEpisode.spec.ts` запускается с `@vitest-environment jsdom` (нужен
`@testing-library/react` `renderHook`), остальные три файла — в `environment: 'node'` (дефолт
`vitest.config.mts`). Сетевой слой (`getAnimeDetails`) и `@letar/animatrona-shared` замоканы —
реальная фабрика (`createApiClient`/`createConnectionStore`) уже покрыта тестами самой библиотеки
(`libs/animatrona-shared/src/**/*.spec.ts`), здесь проверяется только код-обвязка tv.

Кандидаты на следующую волну unit-тестов: `useWatchProgress` (переиспользован из mobile — сверить,
не покрыт ли уже там), логика выбора дорожек внутри `TVTrackSelector`/`TVPlayerControls` (сейчас
покрыта только косвенно, через `usePlayerEpisode`).
