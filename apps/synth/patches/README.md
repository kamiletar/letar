# Опубликованные патчи

Готовые патчи (JSON), которыми ты решил поделиться — **отслеживаются Git и публичны**, их читает витрина `/gallery`.

Черновики храни в `private/patches/` (в `.gitignore`) или в студии (IndexedDB).
Когда патч готов — перенеси/опубликуй сюда. FM-патчи можно дополнительно экспортировать в `.syx`.
