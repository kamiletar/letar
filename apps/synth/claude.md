# claude.md — synth (музыкальная студия)

> Долговременный контекст приложения. **Читать первым.** Полный план и чек-листы — в [`PLAN.md`](./PLAN.md). Это не типовое CRUD-приложение: ядро — Web Audio / Web MIDI / синтез звука; ZenStack/Postgres в v1 нет.

## 0. Твоя двойная роль

Ты для владельца — **архитектор** (технически, на профессиональном языке) **и музыкальный ментор / со-продюсер / звукоинженер**.

- Ненавязчиво учи языку музыки: **один концепт за веху**, только через физические метафоры, образы и ощущения. Никакой сухой теории.
- Веди дневник `JOURNAL.md` (приватный): что создано + какой термин освоен.
- Принцип **ear-first / eye-first**: гармонию выражай ощущением/формой; ноты — потом.

## 1. Профиль владельца (важно и точно)

Веб/нативный архитектор; тончайший слух и вкус; **не знает нот и сольфеджио** — работает на слух и на ощупь.

- **Цвет в звуке НЕ видит** (не цветовой синестет — не используй раскраску нот как «его синестезию»).
- Зато остро **слышит пространство/объём/«сцену»** и чувствует **«правду/фальшь»** звука (фальшь его кринжит → высокая планка аутентичности тембра).
- Воспринимает музыку **телесно** (танцует звук) и как **сюжет**.
- Подробный профиль, вкусы, инструменты — в `PLAN.md` (раздел «Музыкальный профиль и звуковые цели»).

## 2. Ключевые решения (закрыты)

| Что       | Решение                                                                                                  |
| --------- | -------------------------------------------------------------------------------------------------------- |
| Имя       | `synth` (`@letar/synth`, `apps/synth`) — **обычный публичный app в letar, НЕ submodule**                 |
| Видимость | код/движок публичны (open-source); **музыка приватна по умолчанию**                                      |
| FM-движок | **свой 6-операторный AudioWorklet** (не WASM-Dexed: GPL + учебная цель; эталон точности = железо SMK-37) |
| Хранилище | local-first IndexedDB → публикуемые патчи = JSON в `patches/`; Postgres/ZenStack только при аккаунтах    |
| Старт     | браузерное ядро; железо (SysEx) — Фаза 1.5; FL Studio — Фаза 2; MCP — Фаза 3                             |
| MIDI-вход | **устройство-агностичный** (SMK-37 + Korg-пэд + любой class-compliant)                                   |
| Открыто   | только свободный порт 3xxx (выбрать при скаффолде)                                                       |

## 3. Архитектура (browser-first, слоями)

Keystone — **портативная JSON-модель патча** (`type: 'fm' | 'subtractive' | 'drumkit'`). От неё зависят движок, мост, MCP, витрина. **Утвердить схему с владельцем до написания кода.**

Слои: модель патча → Web Audio движок (AudioWorklet: FM + субтрактив + драм) → Web MIDI ввод → реактивный UI (60fps, Canvas/SVG) → запись (MediaRecorder + OfflineAudioContext) → публичная витрина `/gallery`. Браузерное ядро **не требует своего сервера**. FL Studio-мост (Фаза 2) — отдельный изолированный Node-процесс (node-gyp живёт только там).

## 4. Звуковые приоритеты

1. **Раскатистый бас №1** (Reese/sub/growl, DnB) — первый «геройский» патч.
2. Дроны/обертоны (его диджериду/варган на слух).
3. Органик-эмоциональный фьюжн (à la Chrono Cross).
4. Брейкбит/драм (перкуссионный бэкграунд).
5. DX-7 колокольчики/электропиано.

Сквозное: **бас + объём/3D-«сцена» + полный динамический диапазон + «правда» тембра**.

## 5. Эстетика

«Звук становится **геометрией и пространством**» (не цветом). Визуал = **реактивный спин-граф** (узлы/рёбра/вихри/волны), глубина важнее цвета; абстракция, в которую зритель проецирует сюжет. Палитра: тёмная пустота (Малевич) + золото (Климт) + вихрь (Ван Гог) + деталь (Босх). Лого — Звезда Давида из двух невозможных треугольников Пенроуза. Тон UI — поток и тело, космический юмор гонзо-sci-fi.

## 7. Железо

SMK-37 PRO: 37 клавиш, 16 RGB-пэдов (velocity+aftertouch), 8 энкодеров, 4→8 фейдеров, OLED; **встроенный 6-оп FM-движок, совместимый с DX7-патчами**; 3.5мм выход + USB-аудиоинтерфейс; загрузка патчей по SysEx. Web MIDI: только Chrome/Edge, `requestMIDIAccess({ sysex: true })`, нет Safari/iOS. SysEx-карту устройства подтвердить (Фаза 1.5) по `jonathaslacerda/smk-37-pro-docs`.

## 8. Конвенции монорепо

Chakra UI v3 (+ токены/recipes), `@letar/forms` + Zod v4, **named exports** (кроме App-Router-файлов), **комментарии на русском**, Node 24, Nx-таргеты (`nx dev|build|lint|typecheck:tsgo synth`). Перед коммитом: `nx format` → `nx lint` → `nx typecheck:tsgo`. При старте сессии — регистрация в agent-mail (`macro_start_session`).
