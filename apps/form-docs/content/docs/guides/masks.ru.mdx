## Обзор

`Form.Field.Phone`, `Form.Field.MaskedInput` и все `Form.Document.*` работают на собственном
framework-free движке масок (`@letar/forms-core/mask`) — без сторонних зависимостей вроде
`use-mask-input`/`imask`. `Form.Field.CreditCard` этот движок не использует вовсе: у него
своя алгоритмическая группировка (`@letar/forms-core/credit-card`), не маска в смысле этой
страницы.

Этот гайд — про механику самого движка. Про готовые российские документные поля (ИНН, ОГРН,
БИК и т.д.) — см. [Российские документы](/docs/guides/russian-documents).

## Модель токенов

Маска — строка из токенов и литералов. Три встроенных токена:

| Токен | Значение                |
| ----- | ------------------------ |
| `9`   | цифра                     |
| `a`   | буква (латиница/кириллица) |
| `*`   | буква или цифра           |

Всё остальное в шаблоне — литерал, вставляется автоматически и не редактируется пользователем
напрямую (дефисы, пробелы, скобки).

```
СНИЛС           999-999-999 99
Код подразделения  999-999
Паспорт РФ      99 99 999999
```

### Пользовательские токены

Встроенных трёх токенов не хватает там, где нужен собственный алфавит символов или
трансформация введённого символа (например, замена латиницы на кириллицу для госномера РФ).
`MaskOptions.customTokens` принимает токен с `pattern` (какие символы допустимы) и опциональным
`transform` (как символ заменить перед записью):

```tsx
const plateNumberTokens = {
  л: {
    pattern: (char: string) => 'АВЕКМНОРСТУХABEKMHOPCTYX'.includes(char),
    transform: (char: string) => LATIN_TO_CYRILLIC[char.toUpperCase()] ?? char.toUpperCase(),
  },
}
```

Пользовательские токены не могут переопределить встроенные (`9`/`a`/`*`).

### Переменная длина и выбор маски

`mask` — не обязательно одна строка:

```ts
mask: string | string[] | ((raw: string) => string | null)
```

- **Массив** — движок выбирает вариант, под который сырое значение раскладывается лучше
  (больше принятых символов). Например госномер: 2 или 3 цифры региона — два шаблона в массиве.
- **Функция** — маска зависит от самого значения (например, телефон: по первой цифре решить,
  `8` это префикс или ошибка). `null` — «для этого ввода маски нет», поле работает как
  свободный ввод.

## Режимы форматирования (`formatMode`)

```ts
formatMode:
  | 'live'   // маска на каждое нажатие — ДЕФОЛТ
  | 'blur'   // формат применяется при уходе из поля, снимается при возврате
  | 'off'    // только фильтрация по алфавиту токенов, без группировки
```

`'live'` — дефолт этой библиотеки (осознанное решение, не общепринятая рекомендация — см.
[MASK_ENGINE.md](https://github.com/kamiletar/letar/blob/main/libs/forms/MASK_ENGINE.md) §6.6 и
§8 для контекста исследования). У живого режима цена: DOM-контроллер берёт на себя каретку по
трём веткам (вставка/удаление назад/удаление вперёд), IME-composition guard, детект
автозаполнения и собственный undo-стек — без этого живая маска ломает браузерный Ctrl+Z и
скачет курсором. Всё это уже реализовано в `MaskController`, а не оставлено на совести
потребителя поля.

`'live'`-режим технически даёт **неконтролируемый** `<input>`
(`ref`+`defaultValue`, без `value`/`onChange`) — DOM является источником истины, контроллер
пишет в него через `setRangeText()`, что сохраняет нативный undo-стек браузера. Если пишете
собственное поле поверх `useMaskField`, учитывайте это в разметке — попытка передать `value`
и `onChange` вместе с `'live'` конфликтует с посимвольной записью контроллера.

## Когда маска не нужна

Критерий из дизайн-системы Контур, подтверждённый разбором в MASK_ENGINE.md §5.3:

> Маску показывать, когда нужно ввести определённое количество символов и когда в формате есть
> разделители. Если количество символов может быть разным — маска не показывается.

Практически: **фиксированная длина + разделители → маска. Переменная длина → маска вредит**
(риск обрезки при вставке/автозаполнении, а не помощь).

Отсюда конкретные решения для готовых полей:

| Поле                        | Маска?  | Почему                                              |
| ---------------------------- | ------- | ---------------------------------------------------- |
| `Form.Document.SNILS`        | да      | фиксированная длина, разделители есть                |
| `Form.Document.DepartmentCode` | да    | `999-999`, фиксированная длина                       |
| `Form.Document.INN`          | **нет** | 10 или 12 цифр — переменная длина, разделителей нет  |
| `Form.Document.BirthCertificate` | **нет** | римская часть переменной длины (1–5 знаков) — маска невыразима |

Для полей без маски (`ИНН`, свидетельство о рождении) движок не подключается вообще — только
нормализация и валидация контрольной суммы через `zRu`-схемы.

## Требования доступности

`formatMode: 'live'` без этих требований воспроизводит провал WCAG 3.3.3, найденный при
тестировании USWDS (4 из 5 участников со скринридером не понимали, что символ был отвергнут).
Поэтому в `Form.Field.MaskedInput` они не опциональны:

1. **`formatDescription` обязателен** (WCAG 3.3.2 — формат известен до начала ввода). Без него
   — `console.error` в любой сборке, не только в dev (`NODE_ENV` не используется как гейт — см.
   правило репозитория про этот антипаттерн).
2. **Отвергнутый символ объявляется через `aria-live="polite"`** — никогда `"assertive"`.
   Включено по умолчанию, отключить нельзя через API.
3. **Шаблон маски никогда не попадает в `value`.** Иначе скринридер зачитывает подчёркивания
   placeholder-а как содержимое поля, а автозаполнение Chrome не предлагает подстановку
   (поле считается непустым).
4. **`type="text"` + `inputmode="numeric"`** для цифровых масок, никогда `type="number"` — у
   числового инпута недоступен Selection API, без которого не работает каретка.

```tsx
<Form.Field.MaskedInput
  name="departmentCode"
  label="Код подразделения"
  mask="999-999"
  formatDescription="Формат: 3 цифры, дефис, 3 цифры"
/>
```

## Кастомное поле поверх движка

Готовые документные поля построены на `createDocumentField` — тонкой фабрике над `useMaskField`
(см. [Российские документы](/docs/guides/russian-documents) для примера). Для полей вне
`Form.Document.*` используйте `Form.Field.MaskedInput` напрямую или хук `useMaskField` из
`@letar/forms-react`, если нужна полностью своя разметка.
