## Обзор

Формы — основная поверхность атаки для ботов, спама и вредоносных загрузок. @letar/forms предоставляет три встроенных механизма безопасности, требующих минимальной настройки.

## Honeypot — ловушка для ботов

Скрытое поле, невидимое для людей. Боты заполняют все поля — если это поле содержит значение, отправка молча блокируется.

```tsx
<Form honeypot={true} initialValue={data} onSubmit={handleSubmit}>
  <Form.Field.String name="email" />
  <Form.Field.Textarea name="message" />
  <Form.Button.Submit>Отправить</Form.Button.Submit>
</Form>
```

**Как это работает:**

- Рендерит скрытый `<input>` с `display:none`, `aria-hidden`, `tabIndex=-1`
- Имя поля рандомизируется при каждом рендере (useId + случайный суффикс)
- Если поле содержит любое значение при отправке, форма молча ничего не делает
- Нулевое влияние на UX для реальных пользователей

## Ограничение частоты отправок

Клиентское ограничение отправок с обратным отсчётом. Сохраняется в `sessionStorage`.

```tsx
<Form rateLimit={{ maxSubmits: 3, windowMs: 60000 }} initialValue={data} onSubmit={handleSubmit}>
  <Form.Field.String name="email" />
  <Form.Button.Submit>Отправить</Form.Button.Submit>
</Form>
```

| Свойство     | Тип      | Описание                               |
| ------------ | -------- | -------------------------------------- |
| `maxSubmits` | `number` | Макс. отправок за временное окно       |
| `windowMs`   | `number` | Временное окно в миллисекундах         |

**Поведение:**

- Отслеживает временные метки отправок в `sessionStorage`
- При достижении лимита показывает алерт с обратным отсчётом
- Плавная деградация: если `sessionStorage` недоступен, отправка всегда разрешена
- **Важно:** Должно сочетаться с серверным ограничением частоты для реальной защиты

## Безопасная загрузка файлов

Повышенная безопасность для `Form.Field.FileUpload` с проверкой MIME, удалением метаданных и переименованием файлов.

```tsx
<Form.Field.FileUpload
  name="document"
  security={{
    maxSize: '10MB',
    allowedTypes: ['image/jpeg', 'image/png', 'application/pdf'],
    stripMetadata: true,
    renameFile: true,
  }}
/>
```

| Свойство        | Тип                | Описание                                                |
| --------------- | ------------------ | ------------------------------------------------------- |
| `maxSize`       | `string \| number` | Макс. размер файла (`'10MB'`, `'500KB'` или байты)      |
| `allowedTypes`  | `string[]`         | Допустимые MIME-типы, проверяются через magic bytes      |
| `stripMetadata` | `boolean`          | Удалить EXIF-данные из изображений (перекодировка Canvas)|
| `renameFile`    | `boolean`          | Заменить имя файла на UUID (защита от path traversal)    |

**Определение MIME** считывает первые 4-8 байт файла для сопоставления с известными сигнатурами (magic bytes), а не расширение файла. Поддерживаемые типы: JPEG, PNG, GIF, WebP, PDF, ZIP.

**Удаление EXIF** использует Canvas API: изображение рисуется на canvas и экспортируется обратно, удаляя все метаданные, включая GPS-координаты, информацию о камере и т.д.

**Переименование файлов** заменяет оригинальное имя файла на UUID, сохраняя расширение, предотвращая атаки path traversal вроде `../../etc/passwd`.

## Комбинирование механизмов безопасности

Все три можно использовать вместе:

```tsx
<Form honeypot={true} rateLimit={{ maxSubmits: 5, windowMs: 300000 }} initialValue={data} onSubmit={handleSubmit}>
  <Form.Field.String name="name" />
  <Form.Field.String name="email" />
  <Form.Field.FileUpload
    name="avatar"
    security={{
      maxSize: '5MB',
      allowedTypes: ['image/*'],
      stripMetadata: true,
      renameFile: true,
    }}
  />
  <Form.Button.Submit>Отправить</Form.Button.Submit>
</Form>
```

## Утилитарные функции

Экспортируются для автономного использования:

```tsx
import { parseFileSize, validateMimeType, sanitizeFileName } from '@letar/forms'

parseFileSize('10MB') // 10485760
sanitizeFileName(file) // File с UUID-именем
await validateMimeType(file, ['image/jpeg']) // { valid: true, detectedMime: 'image/jpeg' }
```
