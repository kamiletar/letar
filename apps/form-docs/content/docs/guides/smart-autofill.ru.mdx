## Обзор

Правильные атрибуты `autocomplete` улучшают конверсию форм на **30%** (Google) и соответствуют **WCAG 1.3.5** для полей персональных данных. @letar/forms автоматически устанавливает `autocomplete` на основе имён полей — настройка не требуется.

## Как это работает

Поля с именами `email`, `phone`, `firstName` и т.д. автоматически получают правильный атрибут `autocomplete`:

```tsx
<Form schema={Schema} initialValue={data} onSubmit={save}>
  <Form.Field.String name="email" /> {/* autocomplete="email" */}
  <Form.Field.String name="firstName" /> {/* autocomplete="given-name" */}
  <Form.Field.Phone name="phone" /> {/* autocomplete="tel" */}
  <Form.Field.Password name="password" /> {/* autocomplete="current-password" */}
  <Form.Field.String name="city" /> {/* autocomplete="address-level2" */}
</Form>
```

Никаких пропсов не нужно — просто работает.

## Поддерживаемые поля

| Паттерн имени поля                 | Значение autocomplete |
| ---------------------------------- | --------------------- |
| `email`, `e-mail`                  | `email`               |
| `phone`, `tel`, `mobile`           | `tel`                 |
| `firstName`, `first_name`          | `given-name`          |
| `lastName`, `last_name`, `surname` | `family-name`         |
| `name`, `fullName`                 | `name`                |
| `password`                         | `current-password`    |
| `newPassword`, `confirmPassword`   | `new-password`        |
| `address`, `street`                | `street-address`      |
| `city`                             | `address-level2`      |
| `state`, `region`                  | `address-level1`      |
| `zip`, `postalCode`                | `postal-code`         |
| `country`                          | `country-name`        |
| `company`, `organization`          | `organization`        |
| `username`                         | `username`            |

## Переопределение через схему

Используйте `.meta({ ui: { autocomplete } })` для переопределения автодетекции:

```tsx
const Schema = z.object({
  // Переопределение: использовать street-address вместо значения по умолчанию
  deliveryAddress: z.string().meta({
    ui: { title: 'Адрес доставки', autocomplete: 'street-address' },
  }),

  // Отключить автозаполнение для этого поля
  secretCode: z.string().meta({
    ui: { title: 'Секретный код', autocomplete: 'off' },
  }),
})
```

## Переопределение через пропсы

Пропс `autoComplete` всегда имеет приоритет:

```tsx
<Form.Field.String name="email" autoComplete="username" />
```

## Приоритет

1. **Пропс `autoComplete`** (наивысший)
2. **`.meta({ ui: { autocomplete } })`** из Zod-схемы
3. **Автодетекция** по имени поля

## Вложенные поля

Для вложенных путей типа `address.city` автодетекция использует **последний сегмент** (`city`):

```tsx
<Form.Group name="billing">
  <Form.Field.String name="city" /> {/* autocomplete="address-level2" */}
  <Form.Field.String name="zip" /> {/* autocomplete="postal-code" */}
</Form.Group>
```

## Затронутые компоненты

Автодетекция работает для:

- `Form.Field.String`
- `Form.Field.Password`
- `Form.Field.Textarea`
- `Form.Field.Phone` (всегда `tel`)
