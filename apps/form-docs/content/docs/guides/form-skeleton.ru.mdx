## Обзор

`Form.Skeleton` генерирует загрузочный плейсхолдер, повторяющий структуру формы. Компонент читает схему и создаёт скелетон-бары подходящего размера для каждого типа поля.

```tsx
import { Form } from '@letar/forms'

{/* Пока данные загружаются */}
<Form.Skeleton schema={UserSchema} showSubmit />

{/* Или inline: форма сама показывает скелетон при загрузке */}
<Form schema={UserSchema} loading={isLoading} initialValue={data} onSubmit={save}>
  <Form.Field.String name="name" />
  <Form.Field.String name="email" />
  <Form.Button.Submit>Сохранить</Form.Button.Submit>
</Form>
```

## Пропсы

| Проп         | Тип         | По умолчанию | Описание                              |
| ------------ | ----------- | ------------ | ------------------------------------- |
| `schema`     | `ZodObject` | обязателен   | Схема для генерации скелетона         |
| `showSubmit` | `boolean`   | `false`      | Показать скелетон кнопки внизу        |
| `fields`     | `number`    | авто         | Переопределить количество полей       |

## Standalone и Inline

**Standalone** — рендерить скелетон как отдельный компонент:

```tsx
{
  isLoading ? (
    <Form.Skeleton schema={Schema} showSubmit />
  ) : (
    <Form schema={Schema} initialValue={data} onSubmit={save}>
      ...
    </Form>
  )
}
```

**Inline** — использовать проп `loading` на самой форме:

```tsx
<Form schema={Schema} loading={!data} initialValue={data ?? {}} onSubmit={save}>
  <Form.Field.String name="name" />
  <Form.Button.Submit />
</Form>
```

Когда `loading` равен `true`, форма отображает скелетоны вместо полей.

## Как это работает

Схема анализируется для подсчёта полей и определения их типов. Каждый тип поля соответствует скелетон-бару подходящей высоты (текстовые поля → одна строка, textarea → несколько строк и т.д.).
