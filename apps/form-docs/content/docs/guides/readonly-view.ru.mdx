---

## Обзор

`Form.ReadOnlyView` отображает данные формы в режиме только для чтения, извлекая подписи из `.meta({ ui: { title } })` вашей Zod-схемы. Контекст формы не нужен — только данные и схема.

```tsx
import { Form } from '@letar/forms'

;<Form.ReadOnlyView data={{ name: 'John Doe', email: 'john@example.com', role: 'admin' }} schema={UserSchema} />
```

## Пропсы

| Проп      | Тип                       | По умолчанию | Описание                                   |
| --------- | ------------------------- | ------------ | ------------------------------------------ |
| `data`    | `Record<string, unknown>` | обязателен   | Данные для отображения                     |
| `schema`  | `ZodObject`               | обязателен   | Схема для подписей через `.meta()`         |
| `compact` | `boolean`                 | `false`      | Компактная раскладка (одна строка на поле) |
| `exclude` | `string[]`                | `[]`         | Поля, которые нужно скрыть                 |
| `labels`  | `Record<string, string>`  | `{}`         | Ручное переопределение подписей            |

## Компактный режим

```tsx
<Form.ReadOnlyView data={user} schema={UserSchema} compact />
```

Стандартный режим показывает подпись над значением. Компактный режим показывает подпись и значение на одной строке.

## Сценарии использования

- **Страница профиля**: отображение профиля пользователя без возможности редактирования
- **Шаг подтверждения**: показ введённых данных перед финальным подтверждением
- **Режим печати**: аккуратное отображение данных для печати
- **Страницы деталей**: отображение записей в админ-панелях
