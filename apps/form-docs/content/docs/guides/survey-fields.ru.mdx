## ImageChoice

Визуальный выбор из карточек с изображениями. Идеально для выбора стилей, продуктов или категорий.

```tsx
<Form.Field.ImageChoice
  name="style"
  label="Выберите стиль"
  options={[
    { value: 'modern', label: 'Современный', image: '/img/modern.jpg' },
    { value: 'classic', label: 'Классический', image: '/img/classic.jpg' },
  ]}
  columns={3}
  multiple={false}
/>
```

**Значение:** `string` (одиночный выбор) или `string[]` (при `multiple={true}`)

| Свойство   | Тип                   | По умолчанию | Описание                           |
| ---------- | --------------------- | ------------ | ---------------------------------- |
| `options`  | `ImageChoiceOption[]` | обязательно  | Варианты с изображениями           |
| `columns`  | `number`              | `3`          | Колонки сетки (адаптивно: 1->2->N) |
| `multiple` | `boolean`             | `false`      | Режим множественного выбора        |

## Likert

Шкала согласия/удовлетворённости с подписями. Стандарт для NPS и опросных форм.

```tsx
<Form.Field.Likert
  name="satisfaction"
  label="Насколько вы удовлетворены?"
  anchors={['Очень неудовлетворён', 'Неудовлетворён', 'Нейтрально', 'Удовлетворён', 'Очень удовлетворён']}
  showNumbers={true}
/>
```

**Значение:** `number` (индекс с 1 выбранного пункта)

| Свойство      | Тип        | По умолчанию | Описание                   |
| ------------- | ---------- | ------------ | -------------------------- |
| `anchors`     | `string[]` | обязательно  | Подписи для каждого пункта |
| `showNumbers` | `boolean`  | `false`      | Показывать номера пунктов  |

На мобильных устройствах горизонтальная шкала переключается на вертикальный список.

## YesNo

Бинарный выбор с крупными кликабельными блоками. Подходит для согласий, подтверждений и простых вопросов.

```tsx
<Form.Field.YesNo
  name="agree"
  label="Вы согласны?"
  yesLabel="Да, согласен"
  noLabel="Нет, отказываюсь"
  variant="buttons"
/>
```

**Значение:** `boolean`

| Свойство   | Тип                                | По умолчанию | Описание           |
| ---------- | ---------------------------------- | ------------ | ------------------ |
| `yesLabel` | `string`                           | `'Да'`       | Текст кнопки «Да»  |
| `noLabel`  | `string`                           | `'Нет'`      | Текст кнопки «Нет» |
| `variant`  | `'buttons' \| 'thumbs' \| 'emoji'` | `'buttons'`  | Визуальный стиль   |

Варианты: `buttons` (только текст), `thumbs` (с палец вверх/вниз), `emoji` (со счастливым/грустным лицом).
