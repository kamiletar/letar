## Steps

**API:** `Form.Steps`

Разбейте длинную форму на управляемые шаги:

```tsx
<Form schema={Schema} initialValue={data} onSubmit={save}>
  <Form.Steps animated validateOnNext>
    <Form.Steps.Step title="Личные данные">
      <Form.Field.String name="firstName" />
      <Form.Field.String name="lastName" />
      <Form.Field.String name="email" />
    </Form.Steps.Step>

    <Form.Steps.Step title="Адрес">
      <Form.Field.String name="street" />
      <Form.Field.String name="city" />
      <Form.Field.String name="zip" />
    </Form.Steps.Step>

    <Form.Steps.Step title="Настройки">
      <Form.Field.Checkbox name="newsletter" />
      <Form.Field.Select name="language" />
    </Form.Steps.Step>

    <Form.Steps.Navigation />
  </Form.Steps>
</Form>
```

## Возможности

- **`animated`** — плавные переходы между шагами
- **`validateOnNext`** — валидация текущего шага перед переходом
- **`Form.Steps.Navigation`** — кнопки Назад / Далее / Отправить
- **Индикатор** — отображение прогресса по шагам
- **Навигация клавиатурой** — поддержка стрелок

## Пропсы кнопок навигации

`prevProps`, `nextProps`, `submitProps` и `skipProps` передают дополнительные атрибуты каждой
кнопке — `data-*` (якоря подсказок наставника, `data-testid`, аналитика), `aria-*` и другие
атрибуты нативной кнопки. Литералы `data-*` пишутся без `as`:

```tsx
<Form.Steps.Navigation
  prevProps={{ 'data-assist-id': 'wizard.prev' }}
  nextProps={{ 'data-assist-id': 'wizard.next' }}
  submitProps={{ 'data-assist-id': 'wizard.submit' }}
/>
```

- **«Далее» и «Отправить» — две разные кнопки.** На последнем шаге вместо `nextProps` действует
  `submitProps`; атрибуты с одной кнопки на другую не переезжают.
- `onClick`, `disabled`, `loading` и `type` задаёт сам компонент: в тип пропсов они не входят, а в
  рантайме перекрываются, поэтому навигацию по шагам через эти пропсы не сломать.
- Доступно с `@letar/forms` 2.14.22; те же пропсы есть в `@letar/forms-shadcn`, `@letar/forms-vue`
  и `@letar/forms-vue-shadcn`.

## Экран после завершения

`Form.Steps.CompletedContent` рендерит экран, показываемый после подтверждения последнего шага —
сводку или панель «проверьте перед отправкой»:

```tsx
<Form.Steps validateOnNext>
  <Form.Steps.Step title="Личные данные">...</Form.Steps.Step>
  <Form.Steps.Step title="Адрес">...</Form.Steps.Step>

  <Form.Steps.CompletedContent>
    <p>Всё готово! Проверьте данные и нажмите «Отправить».</p>
  </Form.Steps.CompletedContent>

  <Form.Steps.Navigation />
</Form.Steps>
```

Его присутствие в дереве меняет поведение кнопки на последнем шаге (`@letar/forms` 2.16.0+):
Continue сначала переводит в состояние «завершено» (там рендерится `CompletedContent`), и только
оттуда `Form.Steps.Navigation` переключается на Submit. Без `CompletedContent` последний шаг
по-прежнему отправляет форму сразу — экран завершения подключается по желанию, существующие формы
не затрагиваются.

## Сохранение шагов

Шаги можно сохранять в localStorage для восстановления при перезагрузке страницы:

```tsx
<Form.Steps animated validateOnNext persistKey="checkout-wizard">
  ...
</Form.Steps>
```
