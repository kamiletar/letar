## Обзор

`Form.DebugValues` отображает живое JSON-дерево всех значений формы. Компонент автоматически определяет тёмную/светлую тему и по умолчанию скрыт в production.

```tsx
<Form schema={Schema} initialValue={data} onSubmit={save}>
  <Form.Field.String name="title" />
  <Form.Field.Number name="price" />
  <Form.DebugValues />
  <Form.Button.Submit />
</Form>
```

## Пропсы

| Проп               | Тип       | По умолчанию    | Описание                              |
| ------------------- | --------- | --------------- | ------------------------------------- |
| `title`            | `string`  | `"Form Values"` | Заголовок блока                       |
| `collapsed`        | `number`  | `2`             | Глубина раскрытия JSON-дерева         |
| `showInProduction` | `boolean` | `false`         | Показывать даже в production-сборках  |

## Определение темы

Инспектор автоматически подстраивается под цветовую схему приложения, проверяя:

1. Класс `dark` на `<html>` (next-themes)
2. Атрибут `data-theme="dark"`
3. Свойство `style.colorScheme`

## Когда использовать

- **Во время разработки** — видеть точные значения, которые хранит форма
- **Отладка валидации** — проверить, какие данные доходят до `onSubmit`
- **Сложные формы** — инспектировать вложенные группы и массивы
- **Тестирование схемы** — убедиться, что `.meta()` и трансформы работают корректно

## Переопределение для production

Для отладки на staging или в production:

```tsx
<Form.DebugValues showInProduction />
```

Без `showInProduction` компонент возвращает `null` в production-сборках — нулевое влияние на бандл.
