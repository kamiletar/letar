## Обзор

Формы могут автоматически сохранять состояние в localStorage и восстанавливать его при возвращении пользователя. Это предотвращает потерю данных при случайном обновлении страницы.

## Базовое использование

```tsx
<Form
  schema={Schema}
  initialValue={defaults}
  onSubmit={handleSubmit}
  persistence={{
    key: 'checkout-form',
    debounceMs: 500,
  }}
>
  <Form.Field.String name="name" />
  <Form.Field.String name="email" />
  <Form.Button.Submit>Отправить</Form.Button.Submit>
</Form>
```

## Как это работает

1. **Пользователь печатает** → состояние формы сохраняется в `localStorage` с дебаунсом
2. **Страница обновляется** → появляется диалог: "Восстановить черновик?"
3. **Пользователь нажимает Восстановить** → форма заполняется сохранёнными данными
4. **Пользователь отправляет** → запись в localStorage автоматически удаляется

## Конфигурация

```tsx
persistence={{
  key: 'my-form',              // ключ localStorage (обязательно)
  debounceMs: 500,             // дебаунс сохранения в мс (по умолчанию: 300)
  dialogTitle: 'Восстановить черновик?',
  dialogDescription: 'У вас есть несохранённые изменения.',
  restoreLabel: 'Восстановить',
  discardLabel: 'Отменить',
}}
```

## Кастомное сохранение

Для продвинутых случаев (IndexedDB, серверное хранение) используйте `useOfflineForm` из модуля [Офлайн](/docs/guides/offline).
