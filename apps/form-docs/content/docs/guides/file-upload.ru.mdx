## Полный пример

Полный sandbox-пример, прочитанный напрямую из исходников `form-develop-app` /
`form-develop-app-shadcn` на сборке. Оба источника показывают `Form.Field.FileUpload`;
shadcn-источник (`specialized-demo`) заодно показывает ColorPicker, Editable и Signature (вне
скоупа этого гайда) — та же пара с пересечением, что и на категорийной странице
«Поля → Специализированные». Аналога для Vue/Angular пока нет — эти вкладки показаны как disabled.

## Базовая загрузка

```tsx
const Schema = z.object({
  avatar: z.any().optional().meta({
    ui: { title: 'Фото профиля' },
  }),
})

<Form.Field.FileUpload name="avatar" accept="image/*" />
```

## Множественная загрузка

```tsx
<Form.Field.FileUpload name="documents" maxFiles={5} />
```

## Зона перетаскивания

```tsx
<Form.Field.FileUpload name="files" variant="dropzone" accept="image/*,.pdf" maxSize={5 * 1024 * 1024} />
```

## Пропсы

| Проп       | Тип                      | Описание                        |
| ---------- | ------------------------ | ------------------------------- |
| `accept`   | `string`                 | Типы файлов (`image/*`, `.pdf`) |
| `maxFiles` | `number`                 | Максимум файлов                 |
| `maxSize`  | `number`                 | Максимальный размер в байтах    |
| `variant`  | `'button' \| 'dropzone'` | Вариант UI                      |
