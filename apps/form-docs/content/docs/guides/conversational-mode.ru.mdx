## Обзор

Разговорный режим показывает по одному полю за раз с плавными анимациями, прогресс-баром и навигацией с клавиатуры. Идеален для опросов, онбординга и маркетинговых форм, где важна высокая конверсия заполнения.

## Базовое использование

```tsx
<Form initialValue={data} onSubmit={handleSubmit}>
  <ConversationalMode showProgress showQuestionNumber>
    <Form.Field.String name="name" label="Как вас зовут?" />
    <Form.Field.String name="email" label="Ваш email?" />
    <Form.Field.YesNo name="subscribe" label="Подписаться на обновления?" />
  </ConversationalMode>
</Form>
```

Каждый дочерний элемент становится одним шагом. Пользователь видит одно поле за раз и переходит между ними нажатием Enter или кнопками.

## Пропсы

| Пропс                | Тип          | По умолчанию  | Описание                              |
| -------------------- | ------------ | ------------- | ------------------------------------- |
| `showProgress`       | `boolean`    | `true`        | Показывать прогресс-бар               |
| `showQuestionNumber` | `boolean`    | `true`        | Показывать «Вопрос 3 из 7»            |
| `nextLabel`          | `string`     | `'Далее'`     | Текст кнопки «Далее»                  |
| `prevLabel`          | `string`     | `'Назад'`     | Текст кнопки «Назад»                  |
| `submitLabel`        | `string`     | `'Отправить'` | Текст кнопки отправки (последний шаг) |
| `welcomeScreen`      | `ReactNode`  | —             | Контент перед первым вопросом         |
| `completedScreen`    | `ReactNode`  | —             | Контент после последнего вопроса      |
| `onComplete`         | `() => void` | —             | Вызывается при ответе на все вопросы  |

## Навигация с клавиатуры

| Клавиша             | Действие          |
| ------------------- | ----------------- |
| Enter               | Следующий вопрос  |
| Alt + Стрелка вниз  | Следующий вопрос  |
| Alt + Стрелка вверх | Предыдущий вопрос |

## Кастомный хук

Для создания собственного разговорного интерфейса:

```tsx
import { useConversationalState } from '@letar/forms'

const state = useConversationalState(5) // 5 полей
state.currentIndex // 0
state.progress // 0.2
state.next() // перейти к следующему
state.prev() // вернуться к предыдущему
state.isCompleted // false
```
