## Обзор

`Form.Field.DataGrid` предназначен для редактирования больших наборов данных (100+ строк) с сортировкой, фильтрацией и пагинацией. В отличие от `TableEditor` (для создания новых строк), DataGrid — для редактирования существующих данных.

## Когда использовать

| Сценарий                                        | Компонент                |
| ----------------------------------------------- | ------------------------ |
| Ввод 5-50 новых строк (позиции заказа)          | `Form.Field.TableEditor` |
| Редактирование/просмотр 100+ существующих строк | `Form.Field.DataGrid`    |

## Базовое использование

```tsx
<Form initialValue={{ employees: data }} onSubmit={save}>
  <Form.Field.DataGrid
    name="employees"
    columns={[
      { name: 'name', editable: true, filter: 'text' },
      { name: 'salary', editable: true, align: 'right' },
      { name: 'department', editable: true, filter: 'text' },
    ]}
    pageSize={20}
    rowSelection
  />
  <Form.Button.Submit>Сохранить</Form.Button.Submit>
</Form>
```

## Пропсы

| Пропс            | Тип                             | По умолчанию | Описание                                      |
| ---------------- | ------------------------------- | ------------ | --------------------------------------------- |
| `name`           | `string`                        | обязательно  | Имя поля-массива                              |
| `columns`        | `DataGridColumnDef[]`           | обязательно  | Определения столбцов                          |
| `pageSize`       | `number`                        | `20`         | Строк на странице                             |
| `rowSelection`   | `boolean`                       | `false`      | Включить выбор строк чекбоксами               |
| `onRowSave`      | `(row, index) => Promise<void>` | —            | Колбэк сохранения строки                      |
| `virtualized`    | `boolean`                       | `false`      | Виртуальный скроллинг для 1000+ строк         |
| `virtualHeight`  | `string`                        | `'500px'`    | Высота контейнера в виртуализированном режиме |
| `columnResizing` | `boolean`                       | `false`      | Изменение ширины столбцов перетаскиванием     |
| `size`           | `'sm' \| 'md' \| 'lg'`          | `'sm'`       | Размер таблицы                                |

## Определение столбцов

```typescript
interface DataGridColumnDef {
  name: string
  label?: string
  editable?: boolean // по умолчанию: true
  filter?: 'text' | 'range' | 'select' | 'date'
  align?: 'left' | 'center' | 'right'
  width?: string
}
```

## Возможности

- **Сортировка** — клик по заголовку столбца для сортировки (↑ по возрастанию, ↓ по убыванию)
- **Фильтрация** — текстовый ввод для каждого столбца
- **Пагинация** — кнопки «Назад»/«Далее», номер страницы (отключена при `virtualized`)
- **Виртуализация** — плавная прокрутка для 1000+ строк с `virtualized={true}`
- **Изменение ширины столбцов** — перетаскивание границ столбцов с `columnResizing={true}`
- **Изменение порядка столбцов** — перетаскивание заголовков для смены порядка
- **Инлайн-редактирование** — клик по ячейке для редактирования, Enter для сохранения, Escape для отмены
- **Подсветка изменений** — отредактированные ячейки выделяются жёлтым
- **Выбор строк** — чекбокс для каждой строки, выбрать все, массовое удаление
- **Сохранение по строкам** — `onRowSave` срабатывает при редактировании ячейки
- **Экспорт CSV** — скачивание всех данных в CSV-файл
