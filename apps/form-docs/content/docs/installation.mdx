## Install

```bash
npm install @letar/forms @tanstack/react-form @chakra-ui/react zod framer-motion
# or with bun
bun add @letar/forms @tanstack/react-form @chakra-ui/react zod framer-motion
# or with pnpm
pnpm add @letar/forms @tanstack/react-form @chakra-ui/react zod framer-motion
```

## Optional Dependencies

Six peer dependencies are required (`react`, `@chakra-ui/react`, `@tanstack/react-form`, `framer-motion`, `react-icons`, `zod`). Heavy fields need their own packages only when you use them.

For drag & drop reordering (`@letar/forms/sortable`, `@letar/forms/table-editor`):

```bash
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```

For `RichText` (`@letar/forms/rich-text`):

```bash
npm install @tiptap/react @tiptap/starter-kit @tiptap/extension-image @tiptap/extension-link @tiptap/extension-placeholder @tiptap/extension-underline
```

For `DataGrid` (`@letar/forms/data-grid`):

```bash
npm install @tanstack/react-table @tanstack/react-virtual
```

For input masking (phone, credit card, etc.):

```bash
npm install use-mask-input
```

## Peer Dependencies

| Package                | Version   | Required |
| ---------------------- | --------- | -------- |
| `react`                | >= 18.0.0 | Yes      |
| `@tanstack/react-form` | >= 1.0.0  | Yes      |
| `@chakra-ui/react`     | >= 3.0.0  | Yes      |
| `framer-motion`        | >= 10.0.0 | Yes      |
| `zod`                  | >= 3.24.0 | Yes      |
| `@dnd-kit/*`           | >= 6.0.0  | Optional |
| `use-mask-input`       | >= 3.0.0  | Optional |

## Setup

Ensure your app has Chakra UI's `ChakraProvider` configured:

```tsx
import { ChakraProvider, defaultSystem } from '@chakra-ui/react'

function App({ children }) {
  return <ChakraProvider value={defaultSystem}>{children}</ChakraProvider>
}
```

That's it! You're ready to use `@letar/forms`.
