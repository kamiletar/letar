## Form.Field.Number

Numeric input with increment/decrement stepper.

```tsx
const Schema = z.object({
  quantity: z.number().int().min(1).max(100).meta({
    ui: { title: 'Quantity' },
  }),
})

<Form.Field.Number name="quantity" />
```

### Auto Constraints

```tsx
z.number().min(0).max(100)
// → min={0} max={100} step={1} on the input

z.number().int()
// → step={1} (integer only)
```
