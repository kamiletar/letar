## Текстовые поля

| Компонент                | Описание                         | Пример                   |
| ------------------------ | -------------------------------- | ------------------------ |
| `Form.Field.String`      | Однострочный текст               | Имя, email, URL          |

## Базовое использование

Все поля работают одинаково:

```tsx
<Form schema={Schema} initialValue={data} onSubmit={save}>
  <Form.Field.String name="fieldName" />
</Form>
```

Тип поля, лейбл, плейсхолдер и валидация берутся из Zod-схемы.
Нужно указать только `name`, совпадающий с ключом в схеме.

## Пользовательские пропсы

Значения из схемы можно переопределить пропами:

```tsx
<Form.Field.String
  name="title"
  label="Свой лейбл"
  placeholder="Свой плейсхолдер..."
  helperText="Дополнительная подсказка"
  required
/>
```
