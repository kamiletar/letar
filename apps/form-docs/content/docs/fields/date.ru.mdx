## Date

**API:** `Form.Field.Date`

Выбор одной даты.

```tsx
const Schema = z.object({
  birthday: z.string().meta({
    ui: { title: 'Дата рождения' },
  }),
})

<Form.Field.Date name="birthday" />
```

## DateRange

**API:** `Form.Field.DateRange`

Выбор диапазона дат (начало — конец).

```tsx
const Schema = z.object({
  period: z.object({
    start: z.string(),
    end: z.string(),
  }).meta({
    ui: { title: 'Период' },
  }),
})

<Form.Field.DateRange name="period" />
```

## DateTimePicker

**API:** `Form.Field.DateTimePicker`

Совмещённый выбор даты и времени.

```tsx
const Schema = z.object({
  eventDate: z.string().meta({
    ui: { title: 'Дата и время события' },
  }),
})

<Form.Field.DateTimePicker name="eventDate" />
```

## Time

**API:** `Form.Field.Time`

Выбор времени.

```tsx
const Schema = z.object({
  startTime: z.string().meta({
    ui: { title: 'Время начала' },
  }),
})

<Form.Field.Time name="startTime" />
```
