## String

**API:** `Form.Field.String`

Стандартное однострочное текстовое поле. Самый распространённый тип.

```tsx
const Schema = z.object({
  name: z.string().min(2).max(100).meta({
    ui: { title: 'Полное имя', placeholder: 'Введите имя' },
  }),
})

<Form.Field.String name="name" />
```

### Автоматические ограничения

Zod constraints автоматически применяются к элементу input:

```tsx
z.string().min(2).max(100)
// → minLength={2} maxLength={100} на <input>

z.string().email()
// → type="email"

z.string().url()
// → type="url"
```

## Textarea

**API:** `Form.Field.Textarea`

Многострочное поле для длинного текста.

```tsx
const Schema = z.object({
  description: z.string().min(10).max(2000).meta({
    ui: { title: 'Описание', placeholder: 'Опишите ваш проект...' },
  }),
})

<Form.Field.Textarea name="description" />
```

## Password

**API:** `Form.Field.Password`

Поле пароля с кнопкой переключения видимости.

```tsx
const Schema = z.object({
  password: z.string().min(8).meta({
    ui: { title: 'Пароль' },
  }),
})

<Form.Field.Password name="password" />
```

## MaskedInput

**API:** `Form.Field.MaskedInput`

Поле с маской формата для структурированных данных. Требует peer-зависимость `use-mask-input`.

Маска задаётся пропом `mask` самого компонента, а не через `ui` в Zod `meta()` — ключа `mask` в
`FieldUIMeta` нет.

```tsx
const Schema = z.object({
  phone: z.string().meta({
    ui: { title: 'Телефон' },
  }),
  creditCard: z.string().meta({
    ui: { title: 'Номер карты' },
  }),
})

<Form.Field.MaskedInput name="phone" mask="+7 (999) 999-99-99" />
<Form.Field.MaskedInput name="creditCard" mask="9999 9999 9999 9999" />
```

## RichText

**API:** `Form.Field.RichText`

Редактор форматированного текста для HTML/markdown контента.

```tsx
const Schema = z.object({
  content: z.string().meta({
    ui: { title: 'Содержание статьи' },
  }),
})

<Form.Field.RichText name="content" />
```

Требуются peer-зависимости: `@tiptap/react` и `@tiptap/starter-kit`.

## Slug

**API:** `Form.Field.Slug`

Текстовое поле-«зеркало»: значение — URL-слаг, производный от соседнего поля (обычно названия),
пока пользователь не отредактирует слаг вручную — после этого зеркалирование выключается
навсегда для этой формы.

```tsx
const Schema = z.object({
  name: z.string().meta({ ui: { title: 'Название' } }),
  slug: z.string().meta({ ui: { title: 'URL' } }),
})

<Form.Field.String name="name" />
<Form.Field.Slug name="slug" source="name" />
```

**На форме редактирования** (слаг уже непустой при монтировании — у записи опубликованный
адрес) зеркалирование по умолчанию **выключено**: молча менять URL, на который уже ведут внешние
ссылки, нельзя. Включить — `syncOnEdit`:

```tsx
<Form.Field.Slug name="slug" source="name" syncOnEdit={!isPublished} />
```

**Props:** `source` (обязательно — имя соседнего поля в той же группе), `syncOnEdit` (по
умолчанию `false`), `slugify` (кастомная функция транслитерации, по умолчанию `slugify()` из
`@letar/format-utils`, транслитерация кириллицы по ГОСТ 7.79-2000), `maxLength`, `autoComplete`.

## Editable

**API:** `Form.Field.Editable`

Инлайн-редактирование — клик по тексту для редактирования, Enter или blur для сохранения.

```tsx
<Form.Field.Editable name="nickname" />
```
