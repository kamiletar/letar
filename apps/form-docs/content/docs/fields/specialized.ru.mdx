## Phone

**API:** `Form.Field.Phone`

Ввод номера телефона с маской формата.

```tsx
const Schema = z.object({
  phone: z.string().meta({
    ui: { title: 'Телефон' },
  }),
})

<Form.Field.Phone name="phone" />
```

## PinInput

**API:** `Form.Field.PinInput`

```tsx
const Schema = z.object({

    ui: { title: 'Код подтверждения' },
  }),

<Form.Field.PinInput name="code" />
```

## Tags

**API:** `Form.Field.Tags`

Ввод тегов — множественные текстовые значения.

```tsx
const Schema = z.object({
  skills: z.array(z.string()).meta({
    ui: { title: 'Навыки' },
  }),
})

<Form.Field.Tags name="skills" />

// С ограничением количества
<Form.Field.Tags name="skills" maxTags={5} />
```

## FileUpload

**API:** `Form.Field.FileUpload`

Загрузка файлов — кнопка или зона перетаскивания.

```tsx
const Schema = z.object({
  avatar: z.any().optional().meta({
    ui: { title: 'Аватар' },
  }),
})

<Form.Field.FileUpload name="avatar" accept="image/*" />

// Множественная загрузка
<Form.Field.FileUpload name="documents" maxFiles={5} />
```
