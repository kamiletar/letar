## Установка

```bash
npm install @letar/forms@next @tanstack/react-form @chakra-ui/react zod framer-motion react-icons
# или с bun
bun add @letar/forms@next @tanstack/react-form @chakra-ui/react zod framer-motion react-icons
# или с pnpm
pnpm add @letar/forms@next @tanstack/react-form @chakra-ui/react zod framer-motion react-icons
```

`@next` — канал 3.x. Пока 3.x не переведена в `latest`, `@letar/forms` без тега ставит старую ветку 1.x.

## Опциональные зависимости

Обязательных peer-зависимостей шесть (`react`, `@chakra-ui/react`, `@tanstack/react-form`, `framer-motion`, `react-icons`, `zod`). Тяжёлым полям нужны свои пакеты, только если вы их используете.

Для drag & drop сортировки (`@letar/forms/sortable`, `@letar/forms/table-editor`):

```bash
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```

Для `RichText` (`@letar/forms/rich-text`):

```bash
npm install @tiptap/react @tiptap/starter-kit @tiptap/extension-image @tiptap/extension-link @tiptap/extension-placeholder @tiptap/extension-underline
```

Для `DataGrid` (`@letar/forms/data-grid`):

```bash
npm install @tanstack/react-table @tanstack/react-virtual
```

Для `FormDebugJsonView` (`@letar/forms/debug`):

```bash
npm install @uiw/react-json-view
```

Для офлайн-черновиков (`@letar/forms/offline`):

```bash
npm install idb-keyval
```

Маски ввода (телефон, карта и т.д.) встроены, отдельный пакет не нужен.

## Зависимости

| Пакет                                                         | Версия           | Обязательный                       |
| ------------------------------------------------------------- | ---------------- | ---------------------------------- |
| `react`                                                       | >= 18.0.0        | Да                                 |
| `@chakra-ui/react`                                            | >= 3.0.0         | Да                                 |
| `@tanstack/react-form`                                        | >= 1.0.0         | Да                                 |
| `framer-motion`                                               | >= 10.0.0        | Да                                 |
| `react-icons`                                                 | >= 5.0.0         | Да                                 |
| `zod`                                                         | ^4.0.0           | Да                                 |
| `@dnd-kit/core`                                               | >= 6.0.0         | Нет (`/sortable`, `/table-editor`) |
| `@dnd-kit/sortable`                                           | >= 10.0.0        | Нет (`/sortable`, `/table-editor`) |
| `@dnd-kit/utilities`                                          | >= 3.0.0         | Нет (`/sortable`, `/table-editor`) |
| `@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/extension-*` | >= 3.0.0         | Нет (`/rich-text`)                 |
| `@tanstack/react-table`                                       | >= 8.0.0         | Нет (`/data-grid`)                 |
| `@tanstack/react-virtual`                                     | >= 3.0.0         | Нет (`/data-grid`)                 |
| `@uiw/react-json-view`                                        | >= 2.0.0-alpha.0 | Нет (`/debug`)                     |
| `idb-keyval`                                                  | >= 6.0.0         | Нет (`/offline`)                   |

## Настройка

Убедитесь что в приложении настроен `ChakraProvider`:

```tsx
import { ChakraProvider, defaultSystem } from '@chakra-ui/react'

function App({ children }) {
  return <ChakraProvider value={defaultSystem}>{children}</ChakraProvider>
}
```

Готово! Можно использовать `@letar/forms`.
