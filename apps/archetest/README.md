# Archetest — Тест архетипов

Квиз-платформа для тестирования типа личности. 1955 вопросов по 13 шкалам (10 DSM-5 + 3 дополнительных), система достижений, рангов, публичный лидерборд и кабинет психолога.

> **Текущая версия:** 0.3.0
> **Технологический стек:** Next.js 16, React 19, Chakra UI v3, PostgreSQL, Prisma, ZenStack

## Быстрый старт

### Разработка

```bash
# Запуск dev-сервера
nx dev archetest  # порт 3012

# База данных
nx zenstack:generate archetest  # Генерация Prisma + Zod схем
nx db:push archetest            # Синхронизация БД (dev)
nx db:migrate archetest         # Создание миграции (prod)
nx db:studio archetest          # Prisma Studio
```

### Тестирование

```bash
nx lint archetest               # Линтинг
nx typecheck:tsgo archetest     # Проверка типов (tsgo — быстрее!) ⚡
nx test archetest               # Unit-тесты
nx e2e archetest-e2e            # E2E тесты (Playwright)
nx format archetest             # Форматирование
```

### Деплой

```bash
./deploy-affected.sh --app archetest
```

## Основные функции

### Квиз

- **1955 вопросов** по 13 шкалам (10 DSM-5 + 3 дополнительных)
- **50 вопросов за сессию** — стратифицированная выборка
- Нормализация баллов (0-100%), уровни достоверности и значимости

### Геймификация

- **20+ достижений** с XP наградами
- **15 рангов** (Novice → Explorer → Expert → Master → Guru)
- **Публичный лидерборд** — топ-50 по XP

### Кабинет психолога

- Привязка клиентов по email
- Профиль клиента: радар-график, динамика, топ-3 типа
- Личные заметки, редактируемые имена клиентов

### Прочее

- Аутентификация через Letar Auth (OIDC)
- Интернационализация: русский + английский
- Dark mode
- Страница для профессионалов (DSM-5, дифференциальная диагностика)
