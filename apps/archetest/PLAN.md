## Описание проекта

Квиз-платформа для тестирования типа личности на основе 1955 вопросов по 13 шкалам (10 DSM-5 + 3 дополнительных). Приложение включает систему достижений, рангов, публичный лидерборд и кабинет психолога для работы с клиентами.

### Роли

| Роль             | Описание                                                     |
| ---------------- | ------------------------------------------------------------ |
| **USER**         | Проходит квиз, видит результаты, достижения, ранг            |
| **ADMIN**        | Видит клинические названия, полный доступ                    |
| **PSYCHOLOGIST** | Кабинет с клиентами, заметки, динамика сессий, радар-графики |

### Шкалы теста (13)

**DSM-5 кластер A:** Параноидное (PAR), Шизоидное (SZD), Шизотипическое (SZT)
**DSM-5 кластер B:** Антисоциальное (ANT), Пограничное (BOR), Гистрионическое (HIS), Нарциссическое (NAR)
**DSM-5 кластер C:** Избегающее (AVD), Зависимое (DEP), Обсессивно-компульсивное (OCD)
**Дополнительные:** Биполярное аффективное (BAR), Пассивно-агрессивное (PAG), Депрессивное (DPR)

## Текущее состояние

### Реализовано ✅

- Квиз: 50 вопросов за сессию, стратифицированная выборка, нормализация баллов
- Аутентификация: Better Auth + OIDC (Letar Auth)
- Достижения: 20+ ачивок с XP
- Ранги: 15 рангов (5 тиров × 3 уровня)
- Лидерборд: топ-50, кэшированные данные
- Кабинет психолога: список клиентов, детали, заметки, динамика
- Dark mode
- i18n: ru + en
- Деплой: Docker, standalone
