## Описание проекта

Квиз-платформа для тестирования типа личности на основе 1955 вопросов по 13 шкалам (10 DSM-5 + 3 дополнительных). Приложение включает систему достижений, рангов, публичный лидерборд и кабинет психолога для работы с клиентами.

### Роли

| Роль             | Описание                                                     |
| ---------------- | ------------------------------------------------------------ |
| **USER**         | Проходит квиз, видит результаты, достижения, ранг            |
| **ADMIN**        | Видит клинические названия, полный доступ                    |
| **PSYCHOLOGIST** | Кабинет с клиентами, заметки, динамика сессий, радар-графики |

### Шкалы теста (13)

**DSM-5 кластер A:** Параноидное (PAR), Шизоидное (SZD), Шизотипическое (SZT)
**DSM-5 кластер B:** Антисоциальное (ANT), Пограничное (BOR), Гистрионическое (HIS), Нарциссическое (NAR)
**DSM-5 кластер C:** Избегающее (AVD), Зависимое (DEP), Обсессивно-компульсивное (OCD)
**Дополнительные:** Биполярное аффективное (BAR), Пассивно-агрессивное (PAG), Депрессивное (DPR)

**Этап 5.1 — Новые шкалы (8 штук) — P0**

Новые шкалы расширяют существующие 13 DSM-5 шкал. Ядро теста: **21 шкала (13 + 8)**.

| Код | Название                    | Группа                 |
| --- | --------------------------- | ---------------------- |
| MAC | Макиавеллизм                | Тёмная Триада          |
| HUM | Гуманизм                    | Светлая Триада         |
| KAN | Кантианство (Долг/Мораль)   | Светлая Триада         |
| FAI | Вера в человечество         | Светлая Триада         |
| SAD | Садизм                      | Деструктивные паттерны |
| MAS | Мазохизм ⚠️ бета             | Деструктивные паттерны |
| ASD | РАС / Радикальная честность | Спектр развития        |
| ALX | Алекситимия                 | Спектр развития        |

> **Переиспользование DSM-5 шкал (решение 2026-07-03, устраняет противоречие «8 vs 9 шкал»):**
> NAR (нарциссизм) и PSY (психопатия) НЕ создаются заново. PSY — display-alias существующей
> шкалы ANT (перекрытие конструктов «психопатия ≈ антисоциальность» слишком велико для
> раздельного измерения). В контексте Тёмной триады NAR и ANT отображаются под ярлыками
> «Нарциссизм» и «Психопатия». Экономия: 15 вопросов и шкала-дубль.
> MAS — авторский конструкт (в Dark Tetrad отсутствует), везде помечается «бета».
> Дифференциальное правило: если ASD высокий и мотив = «передача фактов», снизить PSY/SAD на 80%.
> ALX (алекситимия) ≠ ASD: ALX — трудность распознавания/описания своих и чужих эмоций
> (в т.ч. ситуативная, на фоне инвалидации чувств), не черта спектра аутизма. Возможен
> высокий ALX при низком ASD и наоборот — шкалы должны считаться независимо.

- [ ] Сгенерировать по 15 ситуационных вопросов на каждую шкалу (120 новых вопросов)
- [ ] Обратные формулировки (reverse-keyed): ≥ 1/3 вопросов каждой шкалы — защита от acquiescence bias
- [ ] Социальная желательность «тёмных» шкал: только ситуационные вопросы, без само-ярлыков («я жестокий»)
- [ ] Обновить `max-scores-per-question.json` с весами новых шкал
- [ ] Кросс-шкальные правила — **интерпретационным слоем поверх raw, НЕ мутацией баллов**: ASD снижает вес PSY/SAD; высокий MAC+SZD → «Стратег», не психопат. Raw хранится неизменным (воспроизводимость, динамика клиента у психолога, пересчёт при уточнении правил)
