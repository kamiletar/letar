## [0.8.0] - 2026-07-05

### Added

- **Информированное согласие и политика конфиденциальности (этап 5.6.3, 152-ФЗ)**:
  - `_data/disclaimer.ts` — единый источник текста дисклеймера (вынесен из `quiz-intro`)
  - `_components/disclaimer-consent.tsx` — shared-компонент согласия: полный дисклеймер +
    непредотмеченный чекбокс со ссылкой на `/privacy`. Используется в полном квизе и экспрессе
  - **Экспресс теперь тоже гейтит старт согласием** (раньше согласие было только в полном квизе) —
    гость, хранение в localStorage, на сервер ничего не уходит
  - `/privacy` — страница политики конфиденциальности (ru/en): оператор по реестровому номеру
    РКН 77-26-555440, категории данных, правовое основание (согласие), гостевой режим,
    срок хранения, защита, права субъекта (ст. 14–17), контакт privacy@letar.best,
    дисклеймер «не диагностика, не медизделие»
  - E2E `express.spec.ts` обновлён: принимает согласие перед стартом (клик по контролу
    чекбокса — в лейбле есть ссылка на /privacy); 2 passed

### Changed

- `quiz-intro.tsx` отрефакторен на shared `DisclaimerConsent` + `_data/disclaimer.ts`
  (текст дисклеймера больше не дублируется; чекбокс теперь ссылается на `/privacy`)

## [0.6.0] - 2026-07-05

### Added

- **Express Scan — фестивальный экспресс-тест (этап 5.3)** — гостевой режим `/express`:
  - Роут `/express` — 24-вопросный тест без регистрации (8 шкал гексаграммы × 3 вопроса)
  - `express-select.ts` — детерминированное покрытие: выборка по доминантной шкале
    гарантирует ровно 3 вопроса на каждую из 8 шкал (HUM, KAN, FAI, MAC, NAR, ANT, SAD, MAS);
    инъекция `dominantOf`/`shuffle` для тестируемости; 6 unit-тестов (этап 5.8)
  - `getExpressQuestionsAction` — серверная выборка без attention-check'ов (24 вопроса
    слишком мало, чтобы жертвовать покрытием шкал)
  - `ExpressContainer` — гостевой флоу intro → quiz → results; результат считается на
    клиенте и хранится **только в localStorage** (на сервер ничего не отправляется)
  - `ExpressResults` — гексаграмма 8 шкал + краткие описания по группам (Светлая/Тёмная
    триады, деструктивные паттерны), β-бейдж MAS, QR-код на полный тест (`qrcode.react`),
    кнопка «Привязать результат к аккаунту»
  - Привязка к аккаунту передаёт **ответы, а не баллы** — сервер пересчитывает сам через
    существующий `submitQuizAction`; гость откладывает ответы в `PENDING_QUIZ_KEY` и входит,
    XP/ачивки только за серверно-подтверждённые сессии
  - Ссылка «Экспресс» в шапке и мобильном меню; i18n ru+en (namespace `express`)
- Общие хелперы (shared-first, убрано дублирование из `quiz-container`): `seeded-shuffle.ts`
  (mulberry32 + shuffleWithSeed), `client-scoring.ts` (`computeClientScores`),
  `storage-keys.ts` (единый источник ключей хранилища)
