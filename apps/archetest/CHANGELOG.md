# Changelog

Все изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование следует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.34.1] - 2026-09-26

### Security

- Политики доступа (defense-in-depth): пользователь не меняет себе роли; в связи «клиент — психолог» стороны
  неизменяемы, статус и отзыв меняет только клиент (психолог не может вернуть доступ после отзыва), имя клиента —
  только психолог; заметки психолога недоступны по отозванной связи. Миграций нет.

## [0.34.0] - 2026-09-26

### Added

- «Сохранить в PDF» на экране результатов и в карточке клиента у психолога: печать браузера без навигации, кнопок и
  баннеров, в светлой теме; заметки и сообщения психолога в распечатку карточки не попадают.

## [0.33.0] - 2026-09-26

### Added

- Сообщения клиентам: психолог пишет клиенту из его карточки или всем активным клиентам из списка, клиент читает
  их в настройках («Сообщения от психолога», отметка «новое»), психолог видит, прочитано ли. Миграция: таблица
  `PsychologistMessage`.

### Fixed

- Настройки на телефоне: кнопка «Отозвать доступ» больше не выходит за край карточки психолога.

## [0.32.0] - 2026-09-24

### Added

- Кабинет психолога: бейдж «N новых сессий» у клиента — сессии, завершённые после последнего открытия его
  карточки. Миграция: колонка `ClientPsychologistLink.lastSeenAt`.

## [0.31.0] - 2026-09-24

### Added

- Кабинет психолога: фильтр списка клиентов — поиск по имени/email, статус связи, дата привязки, уровень
  ранга; состояние фильтра сохраняется в адресе страницы.

## [0.30.1] - 2026-09-24

### Fixed

- Подсказки и тексты валидации полей форм в английской версии больше не русские: `FormI18nProvider`
  получал жёсткий `locale="ru"`, теперь — локаль страницы.

## [0.30.0] - 2026-09-24

### Added

- Карточка клиента в кабинете: «Карта стабильности» (с трёх сессий) — какие шкалы меняются между
  сессиями сверх шума порции, а какие устойчивы; разведочная разбивка «в грусти / в ресурсе» по mood
  check-in.

## [0.29.0] - 2026-09-24

### Added

- Карточка клиента в кабинете: график «Динамика тёмного ядра» — уровень индекса по каждой сессии с
  интервалом. График «Динамика результатов» показывает нормализованные баллы (%) вместо сырых, которые
  были несравнимы между сессиями; в динамику идут только валидные сессии. Без миграции: баллы сессии
  пересчитываются по её ответам.

## [0.28.46] - 2026-09-24

### Fixed

- Кабинет психолога: страница настроек клиента падала сразу после привязки психолога, а список клиентов у
  психолога — после первого отзыва доступа (политика `User` отдавала связанного пользователя как `null`).
  Связанные люди теперь дочитываются узким `select`. Найдено новым E2E `cabinet.spec.ts`.

## [0.28.45] - 2026-09-24

### Fixed

- Тесты server actions: выборка вопросов и вход `submitQuizAction`, XP лидерборда, действия кабинета
  психолога (19). Внутренний пересчёт лидерборда больше не публичный server action: `recalcLeaderboardEntry`
  с произвольным `userId` мог вызвать любой клиент.

## [0.28.44] - 2026-09-24

### Fixed

- Достижения «Доминанта» и «Баланс» больше не учитывают скрытые экспериментальные шкалы — раньше
  ачивку можно было получить за доминанту, которую пользователь не видит. Правила вынесены в
  `_lib/achievement-rules.ts` и покрыты тестом (14).

## [0.28.43] - 2026-09-24

### Fixed

- Стратифицированная выборка: при почти исчерпанных редких шкалах порция выходила короче заявленной
  (46 вопросов вместо 50) — слоты, срезанные по размеру корзины, терялись. Теперь они уходят шкалам с
  запасом вопросов. Тесты `stratified-shuffle.test.ts` (5).

## [0.28.42] - 2026-09-24

### Changed

- Волна 5 закрыта: оставшиеся строки интерфейса (гексаграмма, радар, блок психолога, «Состояния»,
  прогресс-бар, метаданные) перенесены в `messages`. Общий хук `useScaleConfidenceLabel`. Исправлено: имя
  психолога `null` больше не выводится строкой «null»; в тесте кабинета добавлены `key` (ошибка oxlint).

## [0.28.41] - 2026-09-24

### Changed

- Проп `isRu` убран у шести компонентов (safety-net, дисклеймер, mood check-in, лид-форма психолога):
  локаль они берут из next-intl сами. Строки — в `messages` (`disclaimer`, `moodCheckIn`, `leadForm`),
  согласия со ссылкой — одним `t.rich`. Тест (4).

## [0.28.40] - 2026-09-24

### Changed

- Профиль и квиз: строки `profile-details`, `developmental-profile-card` и тостов `quiz-container`
  перенесены в `messages` (`profileDetails`, `developmentalCard`, `quiz.container`). Исправлена склейка
  переменных в заголовке модификатора (в RU подставилось бы английское название шкалы). Тест (4).

## [0.28.39] - 2026-09-24

### Changed

- Кабинет психолога: строки блоков «Тёмное ядро», «Экспериментальные шкалы», графика динамики и
  заголовков карточки клиента перенесены в `messages` (`cabinet.darkCore/experimental/dynamicsChart`).
  «Выше/ниже» — ICU `select`, подписи покрытия банка — ключи `confidence.*`. Тест блоков (6).

## [0.28.38] - 2026-09-24

### Changed

- Страница «Если вы психолог» переведена на next-intl: все строки — в `messages/{ru,en}.json`
  (namespace `forProfessionals`), списки — `t.raw`, ссылка на кабинет — `t.rich`. Содержимое вынесено в
  `ForProfessionalsView` и покрыто тестом (4). В vitest добавлен точный alias `@letar/ui` для `vi.mock`.

## [0.28.37] - 2026-09-24

### Added

- Подключён гейт `theme:check` (`@letar/theme-check`, в `dependsOn` у `lint`). Allowlist: metadata
  `themeColor`, satori-иконка, категориальная палитра шкал для recharts — с пояснениями в скрипте.

## [0.28.36] - 2026-09-24

### Changed

- Радар профиля: `accessibilityLayer` выставлен явно (фокус по Tab, оси — стрелками, тултип
  открывается с клавиатуры). Новый компонентный тест `personality-radar-chart.spec.tsx` (2).

## [0.28.35] - 2026-09-24

### Changed

- `/dev/presentation`: синий акцент (бейдж и акцентная строка) заменён на токены `brand` — страница
  печати выровнена с остальным интерфейсом.
