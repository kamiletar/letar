## Запуск тестов

```bash
nx test archetest              # Unit-тесты (Vitest)
nx e2e archetest-e2e           # E2E тесты (Playwright)
nx lint archetest              # Линтинг
nx typecheck:tsgo archetest    # Проверка типов
```
