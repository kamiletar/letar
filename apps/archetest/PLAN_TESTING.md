## Инструкция и возврат к результатам — 2026-10-16

- `quiz-resume.spec.tsx`: инструкция после старта, добровольный вход, возвращение к инструкции
  после входа, сохранность начатых ответов, возврат к завершённым результатам после регистрации,
  отмены входа и перезагрузки, сетевой сбой, изоляция аккаунтов и приоритет завершённой очереди.
- `quiz-results.spec.tsx`: регистрация выше диаграмм; ссылки RU/EN сохраняют локаль и якорь результатов.
- `quiz-pending.test.ts`: проверка очереди, запрет чужих результатов и совместимость с экспрессом.
- E2E начала теста теперь проверяют инструкцию и явное продолжение перед настроением.
- Проверки: 409 тестов в 46 файлах, типы и lint обоих проектов; три сценария mood check-in
  прошли в Chromium, включая мобильный с открытым cookie-баннером. Отдельный браузерный прогон
  подтвердил 50 гостевых ответов, восстановление результатов и серверное сохранение после
  локального тестового входа. Внешняя регистрация в Ключнице в этом прогоне не выполнялась.

## Регрессия входа после теста — 2026-10-16

- `quiz-results.spec.tsx` — обе гостевые кнопки ведут на `/sign-in` без префикса,
  `callbackURL` возвращает на выбранный язык. Мок локализованной ссылки учитывает `/en`,
  чтобы больше не скрывать эту ошибку.
- `proxy.spec.ts` — matcher согласован с исключением `sign-in`, расположенным вне `[locale]`.
- TDD: до исправления падали обе языковые проверки и проверка matcher.
- После исправления: 386 тестов в 44 файлах, format, lint и `typecheck:tsgo` прошли.
  Локальный `/sign-in` вернул HTTP 200 для обоих адресов возврата; headless Chromium подтвердил
  OAuth-запрос с `provider: letar-auth` и `callbackURL: /` либо `/en` (запрос перехвачен локально).

## Запуск тестов

```bash
nx test archetest              # Unit-тесты (Vitest)
nx e2e archetest-e2e           # E2E тесты (Playwright)
nx lint archetest              # Линтинг
nx typecheck:tsgo archetest    # Проверка типов
```
