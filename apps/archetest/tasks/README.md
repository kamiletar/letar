# Очередь задач Archetest

Тест архетипов: порционное прохождение полного банка вопросов (десятки шкал, русский и английский),
радар профиля, достижения, кабинет психолога, печать и скачивание отчёта, PWA с офлайн-очередью
отправки. Вход через Ключницу. Версия — в `package.json`.

## Старт

`bun scripts/tasks.mjs next archetest` из корня letar. Затем `show AT-NNN`,
`start AT-NNN --owner archetest-dev`, `note`, `done --summary`.
Формат: [tasks-per-file](/.claude/docs/tasks-per-file.md). Статусы живут только в шапках задач.

## Правила

1. Нет ответа в планах и решение не твоё — `tasks new … --status blocked --blocked-by "kami: …"`
   и бери следующую.
2. Без слова владельца: `git push`, `bun install` и `bun.lock`. Деплой — только заявкой
   `deploy-agent-dev`; после деплоя E2E на staging и `--sync-texts`, если менялись тексты вопросов.
3. Скоринг, ключи шкал и банк вопросов меняются только с проверкой неизменности скоринга и по
   [протоколу ревью](/apps/archetest/docs/question-review/REVIEW_PROTOCOL.md). Приватные заметки
   психолога и ответы пользователей не логировать и не отдавать наружу.
4. Один пункт — один коммит: версия, `CHANGELOG.md`, `format`, `lint`, `typecheck:tsgo`, тесты.

## Справка

- `PLAN.md` (36 КБ) и `PLAN_COMPLETED.md` вместе с `PLAN_COMPLETED_1…10.md` (около 400 КБ)
  заморожены: описание, шкалы, этапы 1–5, история волн. Целиком не читать: `grep -n '^#' PLAN.md`
  и `Read` с `offset` по полю `source`.
- Не заморожены: `PLAN_TESTING.md`, `AGENTS.md`, `docs/` (бриф шкал, ревью банка,
  восстановление теста). `CHANGELOG*.md` ищется `grep`.
