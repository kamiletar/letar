# auth-hub

Хаб аутентификации. Централизованное управление авторизацией через Better Auth с поддержкой OAuth (Google, Yandex, VK, Telegram). Панель администратора для управления пользователями.

`/sign-in` — единый вход и регистрация: сначала Почта, ВКонтакте или Яндекс, затем для почты
ссылка либо существующий пароль. Новый аккаунт создаётся после подтверждения владения почтой
или входа через провайдера. Старый `/sign-up` перенаправляет сюда с сохранением контекста.

[Исследование UX и план проверки с пользователями](../../.claude/docs/auth-hub-unified-entry-ux.md).

## Стек

- **Фреймворк:** Next.js 16 (App Router)
- **UI:** Chakra UI v3
- **Auth:** Better Auth + OAuth
- **БД:** PostgreSQL + Prisma + ZenStack
