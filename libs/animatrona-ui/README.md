# @letar/animatrona-ui

Общие UI-компоненты для экосистемы Animatrona (tracker + web + desktop).

## Установка

```typescript
import { AnimeHeroBase, EpisodeCardBase, PosterLightbox } from '@letar/animatrona-ui'
```

## Компоненты

- `AnimeHeroBase` — hero-секция страницы аниме
- `EpisodeCardBase` — карточка эпизода
- `PosterLightbox` — модальное окно постера
