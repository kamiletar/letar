## Что и зачем

Запросил `mugcup-dev` (тред `form-city-field`, приложение в публичных файлах не называем). Поле «Город»
как выбор из справочника: свободный текст даёт «Москва/москва/Мск/г. Москва», по такому полю нельзя
фильтровать и считать. Нужно любому приложению с городом (доставка, анкеты, школы).

Проверено: `Form.Field.Combobox` и `select-search-field.tsx` есть, готового города и справочника нет.
`extraComboboxes` — копия справочника в каждом приложении, не подходит.

API: `<Form.Field.City name="city" />`, `countries={['RU']}` по умолчанию; директива
`@meta("form.type", "city")`. Значение — строка с каноническим названием (совместимо с текущими
данными); вариант `{ name, region }` заложить.

## Приёмка

- Поиск по подстроке без учёта регистра и ё/е; сначала совпадения с начала; крупные города выше.
- Справочник ~1100 городов РФ с регионом (различать Советск, Железнодорожный), грузится лениво, один
  файл данных в libs, без внешнего API. Источник и лицензию выбирает исполнитель (ОКТМО/OSM/Wikidata).
- 360 px, строки ≥44 px, клавиатура не закрывает выдачу, без hover.
- Экспорт `matchCity(text)` для миграции старых значений.
- Опция «Другой город» со свободным вводом, помеченная в данных (решение координатора, см. журнал).
- Полный каскад: libs/forms, form-develop-app, form-docs, form-example, fields.md (form-mcp),
  директива в zenstack-form-plugin + get_directives, тесты.
